# 《青史志》v1.0.1 更新公告

v1.0.1 现已上线，本次更新聚焦对局体验打磨：

**重点**
- 险招失败即事件终结，不再原地重选
- 属性增减提示改为先逐条弹出、再在正文原位淡入
- 选择选项后朗读立即切换到结果配音

**对局页**
- 去掉「余 N 轮」提示条与梅枝装饰，画面更干净
- 选项附加信息内联跟排，「史」角标缩小移至右下角
- 画卷边框收窄，正文区域更大
- 雷达图与身外属性加投影
- 移动端右上角新增品牌 logo

**移动端**
- 属性区：去标题、雷达放大、进度条加宽、字号统一
- 选择页：立绘卡精确均分不裁切、难度按钮间距拉开、开始按钮下移、漩涡中心提亮
- 回溯按钮缩小并与标题居中成组

**通用**
- 剧情与结果的金线分隔线不再被压扁

祝各位史官落笔无悔。——《青史志》开发组

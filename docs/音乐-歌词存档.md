# 剧本主题曲 · 歌词存档

## 待机 · 《青史引》

- **用途**:主菜单 / 选择页(待机态)播放。进对局时切为该剧本主题曲。
- **风格**:冥想式水墨氛围 —— 古琴、箫为主,稀疏埙、柔和低音弦乐、远处编钟点缀;
  **无鼓**,极慢、空阔、可无缝循环。
- **曲目文件**:`assets/audio/bgm_idle.ogg`(3:13,单轨循环,无人声)

### 结构

```
[Intro]    古琴独奏泛音,大量留白
[Theme]    箫奏出平静、超越时间的主题旋律
[Develop]  埙与柔和低音弦乐轻入,远处编钟点缀
[Return]   古琴与箫合奏,主题再现
[Outro]    渐弱为单音古琴,几近静默,便于无缝循环
```

## 李斯 · 《上蔡叹》

- **调性**:秦风水墨、一生尺度、苍凉悲怆。从「厕鼠仓鼠之叹」到「沙丘之变」,
  终于「具五刑出咸阳东门」的牵犬之叹。
- **风格**:国乐 × 管弦融合 —— 古琴、箫、埙、编钟、太鼓 + 史诗弦乐与铜管;
  60 BPM 慢速叙事,宽混响,男声低吟。
- **语言**:现代诗性白话(意象取自剧本原文,如「人之贤不肖,譬如鼠矣」)。
- **曲目文件**:
  | 版本 | 文件 | 时长 |
  |---|---|---|
  | 无人声版 | `assets/audio/bgm_lisi_inst.ogg` | 3:15 |
  | 有人声版 | `assets/audio/bgm_lisi_vocal.ogg` | 3:48 |

### 歌词意象对照(剧本 → 词)

| 词中意象 | 剧本出处 |
|---|---|
| 瘦小的鼠 / 厕所的墙缝 / 仓中同类膘肥体壮 | 序章《厕鼠与仓鼠》,「人之贤不肖,譬如鼠矣,在所自处耳」 |
| 竹简和砚台都放下 / 跨过那堵薄薄的墙 | 序章「这一砚宿墨,或许不止能写文书」,辞吏求学 |
| 郡县 法度 一条条一样 | 廷尉·并天下,定郡县之议、统一度量文书 |
| 沙丘的夜里 有人递来火把 | 沙丘之变,赵高夜访,改诏立胡亥 |
| 东门的黄犬 / 追一只逃走的兔 / 上蔡的田埂 | 终局「具五刑出咸阳东门」,顾谓其中子曰「吾欲与若复牵黄犬,俱出上蔡东门逐狡兔,岂可得乎」 |
| 位置把我钉在刑场 | 「筹码涌现」——一生攒出的状态,决定终局能选哪条路 |

### 伴奏版(无人声)结构

```
[Pre-Chorus]  埙与大提琴,缓推
[Chorus] 弦乐涌起,太鼓入场,悲怆辽阔
[Verse]  织体回落,古琴与独奏笛
[Pre-Chorus]  张力上行
[Chorus] 高潮,铜管与鼓,最有力
[Bridge]  情绪弦乐,无词吟唱(hum),战鼓
[Outro]  古琴与箫渐弱,归于静默
```

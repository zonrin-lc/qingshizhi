- **风格**:冥想式水墨氛围 —— 古琴、箫为主,稀疏埙、柔和低音弦乐、远处编钟点缀;
  **无鼓**,极慢、空阔、可无缝循环。

### 结构

```
[Intro]    古琴独奏泛音,大量留白
[Theme]    箫奏出平静、超越时间的主题旋律
[Develop]  埙与柔和低音弦乐轻入,远处编钟点缀
[Return]   古琴与箫合奏,主题再现
[Outro]    渐弱为单音古琴,几近静默,便于无缝循环
```

## 李斯 · 《仓中鼠》

- **切口**:以**「仓中鼠」这一个意象**贯穿一生——从厕鼠仓鼠之叹,到一步步走进最高的仓廪,
  终于刑车出咸阳时想牵黄犬出东门。首尾呼应,一个比喻写尽全篇。
- **立意**:他一生都在往"仓"里爬,爬得越高摔得越苦;
  算尽一生还是那只鼠——最想要的不过是回家,做一回自己的主。
- **风格**:秦廷冷峻 —— 青铜编钟、埙、低音弦乐、肃穆铜管,法度森严的压迫感;58 BPM,沉郁恢弘。

## 陈胜 · 《无相忘》

## 项羽 · 《不肯过江东》

- **切口**:只取**乌江渡口那一刻**——亭长撑船来迎,他不肯过江。
  情感内核落在「八千子弟,一个都没剩」(化用《史记》「籍与江东子弟八千人渡江而西,今无一人还」)。
  不做生平全景,只写这一瞬间的抉择与心绪。
- **立意**:他一生没输过一场仗,却在鸿门放走一条龙、在乌江不肯回头;
  到死仍说「天要亡我」。江东还在等一个永远不会回来的人。
  (标题化用李清照「至今思项羽,不肯过江东」。)
- **风格**:国乐 × 管弦融合 —— 太鼓、琵琶、古琴、箫 + 宏大弦乐、铜管、人声合唱;
  60 BPM,悲壮沉郁而内省,男声低吟。
- **语言**:现代诗性白话(意象取自剧本与《史记》原文,如「四面楚歌」「天亡我,非战之罪」)。

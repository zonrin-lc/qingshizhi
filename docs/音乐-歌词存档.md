## 待机 · 《青史引》

- **用途**:主菜单 / 选择页(待机态)播放。进对局时切为该剧本主题曲。
- **风格**:冥想式水墨氛围 —— 古琴、箫为主,稀疏埙、柔和低音弦乐、远处编钟点缀;
  **无鼓**,极慢、空阔、可无缝循环。
- **曲目文件**:`assets/audio/bgm_idle.ogg`(3:13,单轨循环,无人声)

### 结构

```
[Intro]    古琴独奏泛音,大量留白
[Theme]    箫奏出平静、超越时间的主题旋律
[Develop]  埙与柔和低音弦乐轻入,远处编钟点缀
[Return]   古琴与箫合奏,主题再现
[Outro]    渐弱为单音古琴,几近静默,便于无缝循环
```

## 李斯 · 《仓中鼠》

- **切口**:以**「仓中鼠」这一个意象**贯穿一生——从厕鼠仓鼠之叹,到一步步走进最高的仓廪,
  终于刑车出咸阳时想牵黄犬出东门。首尾呼应,一个比喻写尽全篇。
- **立意**:他一生都在往"仓"里爬,爬得越高摔得越苦;
  算尽一生还是那只鼠——最想要的不过是回家,做一回自己的主。
- **风格**:秦廷冷峻 —— 青铜编钟、埙、低音弦乐、肃穆铜管,法度森严的压迫感;58 BPM,沉郁恢弘。
- **语言**:现代诗性白话,间用史书原句(如「泰山不让土壤,河海不择细流」「人之贤不肖,譬如鼠矣」)。

## 项羽 · 《不肯过江东》

- **切口**:一个从不低头的人,最后的选择是「不肯归」——赢过所有的仗,输给"无颜"二字。

```
你把剑,横成江水的眉
这一生不肯低头,最后也不肯回
只留一句:天亡我,非战之罪
让江水,念了千年不回
```

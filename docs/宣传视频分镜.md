# 《青史志》20 秒叙事短片分镜

> 版本：v2.1・2026-10-20（按反馈重写：去玩法、去 UI、纯故事化、结尾悬念；画幅改为横版）
> 画幅：**16:9 横版，输出分辨率 1920×1080**（满足最低 1280×720 要求；如平台要求可直接出 1920×1080，更高规格再升 2560×1440）
> 基调：宋韵水墨 + 烛火夜读的电影感；全程不出现游戏界面、不出现数值、不出现 "选择 / 结局 / 机制" 类词。
> 讲法：一个史官夜读史书的梦。五个历史人物一闪而过，最后回到那只执笔的手 —— 笔停在空白页上，墨将落未落。
> BGM：古琴单音起，中间用环境声（风 / 浪 / 雨）垫，最后 4 秒收回到一声极轻的箫；无鼓点、无燃向配乐。



***

## 一、叙事线



```
夜 · 烛 · 一卷史书
   ↓
史书里五个命运瞬间（每人 1.5s，电影感剪影，不要字幕压角标）
   ↓
翻到最后一页——空白
   ↓
笔悬在空白上方，墨将落未落
   ↓
黑屏。标题。
```

悬念落点：**观众意识到 ——"这一笔" 还没落，而落笔的人是屏幕外的自己。**

## 三、旁白全文（配音稿，约 40 字）

> 太史公的笔…… 停在了最后一页。
> 易水的风，乌江的浪，大泽乡的雨 —— 都还在。
> 可这一页…… 是空白的。



* 音色：中年男声，低沉、沙哑、留气口；像深夜独自在书房说话，不是念广告。

* 语速：每秒约 4 字；"停在了最后一页" 和 "是空白的" 两处要慢，中间留半拍空白。

* **不出现任何游戏词**：不要 "选择 / 结局 / 玩法 / 历史 / 改写 / 对弈 / 偏差 / 多结局"。

## 六、为什么这样改（对应反馈）



1. **去玩法**：删掉了原镜 8 的实机 UI、抉择卡、偏离度条、结算弹层；全片没有一个游戏界面。

2. **去机制符号**：删掉了 "赤色构陷卡"" 逆天印章 ""史传文字" 这类只有玩过的人才懂的符号。

3. **讲故事**：用 "夜读史书 → 五个命运瞬间 → 回到空白页" 这条情绪线串起来，旁白只做连接，不做解说。

4. **悬念结尾**：笔不落墨、最后一页空白、"这一笔等你来落"—— 观众走出片子时，脑子里挂着一个没合上的动作。

5. **20 秒分配**：开场 4s（书房 + 钩子）+ 五人 7.5s + 悬念 6.5s + 落版 2s。

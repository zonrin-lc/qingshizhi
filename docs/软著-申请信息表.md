## 四、提交流程（个人网上办理，免费）

1. 注册/登录中国版权保护中心 `www.ccopyright.com.cn`，进入「计算机软件著作权登记申请」。
2. 在线填写申请表（抄录上表），提交后打印《申请表》并签字。
3. 上传/邮寄材料：签字申请表 + 身份证复印件 + 源代码文档 + 软件说明书。
4. 等待受理与审查，正常周期 30~40 个工作日左右出证（以中心当期公告为准）。
5. 注意：软著登记不审查游戏内容合规；若游戏后续在 TapTap 正式商业化运营，出版层面的版号是另一条独立流程，与软著互不影响。

> 开发组收尾进阶篇，也是整个机制系列的最后一篇。很多玩家问「这选项怎么是灰的、点不动」——这篇把**所有会让选项变灰的门槛**列全，附几个易漏机制。

## 让选项变灰的门槛

除了属性门槛（财富/文才等），还有这些叙事类门槛：

| 门槛 | 含义 |
|---|---|
| flag / notflag | 需要 / 不需要某旗标 |
| minChapter | 章数下限 |
| devMin / devMax | 偏离度区间（太低或太高都锁） |
| weijiMax | 危机上限 |
| quanshiMax / junxinMax | 权势、君心硬上限 |
| zgMax | 隐藏值上限（戒心太高就锁，见进阶篇第 3 篇） |

界面会写明原因，被锁不是 bug，是你还缺条件。**旗标**常一物三用：解锁钥匙 + 结局开关 + 触发章首暗账（见进阶篇第 1 篇）。

## 几个易漏的机制

- **蓄势**：下次事件抉择险招成算 +10（进新章清零），最实在的保命资源。
- **险招失败 = 选项烧毁 + 事件终结**，不是重来（入门篇第 4 篇讲过，这里再强调）。
- **面板数字报实际生效值**，触顶只报真实涨点，不骗你。
- **硬核连卡面数字都抹掉**，只给「耗财 / 费力」。

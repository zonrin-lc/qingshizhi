# 《青史志》官方攻略 · 入门篇（1/6）：新手必读——你这局到底在玩什么

> **《青史志》官方攻略 · 入门篇 第 1 篇 / 共 6 篇**
> 各位玩家好，这里是《青史志》开发组。很多新玩家进局第一反应是：这游戏到底在玩什么？这篇先把「一局的结构」讲清楚，后面的属性、偏离度、行动卡都是在这个框架上长出来的。建议先读这篇，再看后续。

## 一句话理解

你在一局里扮演历史中的一个具体的人。每一张牌都在「顺势」与「改流」之间挪动一寸，而**偏离度**就是你改写历史的幅度——它既是你的风险，也是你的分数。

## 一局是怎么打的

一局 = **若干章**，每章 = **若干回合**，每回合 = 打牌 / 处理事件，章末结算，最后落到一个结局。

```
章首(序章) → 回合循环 → 章末结算 → 下一章 → … → 结局
```

- **回合**：每回合给你 3 张行动卡，另有一条提示条挂着「关键事件卡」（限时 3 回合）。选一张打出去，牌面会结算属性变化与偏离度。
- **关键事件卡**：不占牌位，表现为顶部提示条，带倒计时。倒计时归零，系统强制把你推进这个事件——该面对的抉择躲不掉。
- **事件**：进入事件页就是几个选项，各有门槛与后果。**这是全局最关键的选择**，行动卡只是铺垫。
- **章末**：结算页看这一章的偏离归因、属性差值、可能触发的「历史修正」。
- **结局**：最后一章走完，按你的路线落到一个结局，带印章、评分与十档评级。

![对局页：左上立绘 + 中间卷轴 + 底部手牌 + 右侧属性](img/手机-03-对局页.jpg)

## 记住三件事就够了

1. **事件页的选项 ＞ 行动卡**。行动卡是铺垫，真正的分叉在事件里。
2. **偏离度是你的分数，不是惩罚**。改得越狠，终局「影响」分越高（详见入门篇第 3 篇）。
3. **危机是隐藏的死线**。几乎每个正数收益都在推高它，满 100 就出事（详见入门篇第 5 篇）。

# 《青史志》官方攻略 #2 · 一页速查卡（建议收藏 / 置顶评论）

**章首暗账（自动结算）**
权势≥80 危机+5 · 君心≤15 危机+10 · 财富≤0 声望−5 · 声望≥80且君心<40 危机+10(整局一次) · 财富≥上限90% 危机+8(整局一次)
（危机类暗账都乘难度系数：剧情×0.6 / 普通×1 / 硬核×1.2）

**功业**
功业 = 权势峰值×0.45 + 政绩×0.15 + 功业标记分
标记按名字去重；不能靠刷数值拿，跟着特定选项/章节走

**史评（一字段两用）**
史评 = 50 + 史评原始分×0.5 + 旗标加成（循史结局下限35）
带史评的选项 = 史实选项 = 险招成算升一档（既稳又可能加分）

**寿元**
体魄达阈值 → 折寿点数，用于抵章首衰减值与疾病压力
体魄既是血条，也是折寿额度；前期少花，后期才扛得住

**染病概率**
3% + (45−有效体魄)×0.4% + (有效年龄−55)×0.4%（上限35%）
有效 = 实际值 + 寿元点数（体魄好、年轻更不易病）

**隐藏值（戒心类）**
不可见 · 可当门槛(戒心须≤N) · 第3章起只给状态词 · 决定致死时的结局变体
看不见的第二条危机线

**章末重算**
章末差值 = 真实净变化（触顶回落单列一条），条目之和 = 差值

**一次性闸**
章首「功高震主」「宗室觊觎」「焚书警示」整局只触发一次

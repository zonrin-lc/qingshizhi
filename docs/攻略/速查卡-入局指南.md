# 《青史志》官方攻略 #1 · 一页速查卡（建议收藏 / 置顶评论）

**属性速查（初值 + 四档评语，李斯为例）**
体魄(30)：≥80龙精虎猛/≥55筋骨强健/≥25尚可劳碌/0形销体弱
武力(20)：≥80万夫不当/≥55骁勇善战/≥25习得武艺/0手无缚鸡
文才(40)：≥75学究天人/≥55文采斐然/≥35腹有诗书/0才疏学浅
谋略(50)：≥80算无遗策/≥55深谋远虑/≥25粗通权变/0不谙机心
辩才(45)：≥80舌动九州/≥55口若悬河/≥25能言善对/0拙于言辞
财富(20)：≥70富埒王侯/≥40仓廪充实/≥15尚可维持/0囊中羞涩
名声(10)：≥80天下归心/≥50名动诸侯/≥25小有清名/0默默无闻
权势(5)：≥80权倾朝野/≥50位高权重/≥25位居朝堂/0人微言轻
政绩(0)：≥80功盖当世/≥55政绩斐然/≥25小有建树/0寸功未立
君心(20)：≥70圣眷正隆/≥45简在帝心/≥20不咸不淡/0君臣相疑
危机(10)：≥90命悬一线/≥70流言中心/≥40暗流涌动/0岁月静好

**险招成算**
差 ≤3 点→七成 · 4–6→五成 · 7–9→四成 · 10–12→三成 · 13–15→两成 · ≥16→一成半
（「史实」类选项成算升一档；差 3 点内可赌，9 点以上别赌）

**回溯**
保留偏离度(取大)+成就词条；重置本章旗标；总分 ×0.98/次；终局/死亡后不可用
（剧情无限 / 普通每章1次 / 硬核0次）

**死亡线**
危机 100（致命难度直接死，非致命钳 95）；染病时体魄归零

**评分**
总分 = (功业×0.30 + 存续×0.30 + 史评×0.20 + 影响×0.20) × 难度系数 × (逆天×1.15) × 回溯惩罚
- 功业 = 权势峰值×0.45 + 政绩×0.15 + 功业标记（能刷）
- 影响 = 偏离度×0.6 + 功业×0.4（偏离度是主杠杆）
- 存续 = 结局自带，不能刷

**评级十档**
甲上95 / 甲90 / 甲下85 / 乙上80 / 乙70 / 乙下60 / 丙上50 / 丙40 / 丙下30 / 丁(兜底)

**解锁下一部**
上一部 乙级及以上 + 解锁 3 个不同结局

**常见死法急救**
①危机爆表：提前打保身牌压危机；带⚠高收益先掂量
②财富见底：早期多打兑换攒钱；见底不能求医
③被门闩住（全选项锁死）：先打牌攒门槛，或回溯重排
④漂得太偏：靠守成/兑换压偏离度；回不回就接受这条线
⑤错手赌输：差3点内再赌；优先走史实选项

**术语速查**
偏离度(改写幅度) · 印章(结局性质,非分数) · 险招(硬闯) · 成算(胜率) · 硬门槛(直接锁死) · 关键事件卡(限时3回合) · 抉择卡(独立抉择) · 际遇(随机小事件) · 历史修正(章末改写) · 存续(结局性质分) · 功业 · 史评

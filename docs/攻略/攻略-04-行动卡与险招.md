# 《青史志》官方攻略 · 入门篇（4/6）：行动卡与险招——什么时候该赌

> **《青史志》官方攻略 · 入门篇 第 4 篇 / 共 6 篇**
> 开发组继续。这篇讲「牌怎么打」和「条件不够时怎么赌」。这是上手后最容易踩坑、也最影响体验的一块。

## 五类行动卡：牌面只是「怎么花」

行动卡分五类。它们的差别不在数值高低，而在**花钱的方向**：

| 卡类 | 作用 | 常见代价 |
|---|---|---|
| **进取** | 换影响力或资源，收益大 | 常带偏离度；容易把危机推高 |
| **兑换** | 用财富/资源换别的东西 | 花钱为主，风险小 |
| **守成** | 补短板、稳住属性 | 收益小，几乎不偏离 |
| **保身** | 压危机、养体魄 | 收益最低，是保险牌 |
| **抉择** | 打出去会进入一次独立抉择（另发选项） | 每两轮强制占一个牌位，整局一张只发一次 |

另外还有一张不在池子里的牌：**求医问药**（染病时额外发，占一个牌位，财富 ≤ 0 时不得求医）。

三条通用规则：

- **硬门槛不达，牌根本不出现**：财富类门槛默认是硬门槛（钱不够就是锁死，不是险招）。
- **软门槛不足，牌上带 ⚠ 徽章**：可以冒险（见下文）。
- **同一张牌可以反复打，收益不打折**（引擎有「重复使用收益递减」规则，但五本剧本当前都关掉了）。所以一张好牌打满一章是可行的——只是每打一次，都要重新掂量这次的风险。

## 险招：⚠ 徽章的意思

⚠ 徽章 = 你条件不够，想走这条路就得赌。

| 差距（还差几点） | 成算 | 备注 |
|---|---|---|
| ≤ 3 | 七成 | 几乎稳过 |
| 4–6 | 五成 |  |
| 7–9 | 四成 |  |
| 10–12 | 三成 |  |
| 13–15 | 两成 | 不建议赌 |
| ≥ 16 | 一成半 | 基本别赌 |

![事件选项上的险招徽章：成功率与还差几点](img/手机-11-险招徽章.jpg)

- **「史实」类选项成算升一档**（五成→七成、四成→五成……）：维持历史惯性比「赌赢历史」容易。
- 掷 1–100 骰，点数 ≤ 成算即成。
- **赌输的代价很硬：该选项当场烧毁**（本章此事件内不能再选），而且**险招失败即事件终结**——你不会回到这个事件重选。
- 硬核难度下，卡面与选项上的数字会被抹成「耗财 / 费力 / 费神」，成算也只给档位词。

**一句实用建议**：差 3 点以内可以赌；差 9 点以上别赌，除非这个选项失败了你也无所谓（例如它本来就是去死的选项）。

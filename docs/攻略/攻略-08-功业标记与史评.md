# 《青史志》官方攻略 · 进阶篇（2/4）：功业标记与史评——分数里最重的两块

> **《青史志》官方攻略 · 进阶篇 第 2 篇 / 共 4 篇**
> 开发组继续进阶篇。这篇讲两个玩家最容易算错的东西：**功业标记**和**史评的双重身份**。想刷高分，这两块比堆数值更关键。

## 功业标记：分数里最重的一块

功业 = 权势峰值×0.45 + 政绩×0.15 + **功业标记分**。

标记跟着特定选项 / 章节走，按名去重，**靠刷数值拿不到**（「权势 80」和「拿到丞相」是两件事）。五部标记清单：

| 剧本 | 标记（分） |
|---|---|
| 李斯 | 长史5 · 廷尉8 · 丞相20 · 郡县15 · 书同文15 |
| 荆轲 | 燕使8 · 函图10 · 咸阳12 · 刺秦25 · 斥秦18 |
| 韩信 | 汉中8 · 三秦10 · 破魏10 · 破赵15 · 破齐15 · 齐王20 · 垓下15 |
| 项羽 | 起兵8 · 巨鹿20 · 鸿门10 · 分封12 · 彭城20 |
| 陈胜 | 首义10 · 据陈12 · 张楚20 · 戏亭12 · 荥阳10 |

> 想冲功业分，盯的是「能不能拿到这些标记」，而不是单纯把权势堆高。

## 史评：既算分又当「史实」标记

同一个字段两用：

- 当分数占终局 **20%**；
- 带史评的选项 = **史实选项** = 险招成算升一档（既稳又可能加分，全局最划算）。

「循史」结局史评有下限 35。所以——**走史实线不仅更稳，评分也更有利**，是进阶玩家默认的优解方向。

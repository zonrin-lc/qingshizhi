## 一、章首那几行小字，是自动结算

每次进新章飘出的提示（春秋渐高 / 树大招风 / 失宠于上……）不是叙事，是引擎在背后动你属性。重点：

| 提示 | 触发 | 后果 |
|---|---|---|
| 树大招风 | 权势 ≥ 80 | 危机 +5 × 难度系数 |
| 失宠于上 | 君心 ≤ 15 | 危机 +10 × 难度系数 |
| 门客散去 | 财富 ≤ 0 | 声望 −5 |
| 功高震主 | 声望≥80 且 君心<40 | 危机 +10（整局一次） |
| 宗室觊觎 | 财富 ≥ 上限 90% | 危机 +8（整局一次） |

- 危机类暗账都乘难度系数（剧情 ×0.6 / 普通 ×1 / 硬核 ×1.2）；一次性效果只触发一次。
- **推论**：权势冲 80+、家产逼近上限，是在给自己点火。

## 二、功业标记：分数里最重的一块

功业 = 权势峰值×0.45 + 政绩×0.15 + **功业标记分**。标记跟着特定选项 / 章节走，按名去重，**靠刷数值拿不到**（「权势 80」和「拿到丞相」是两件事）。五部标记清单：

|---|---|

## 三、史评：既算分又当「史实」标记

同一字段两用：当分数占 20%；带史评的选项 = **史实选项** = 险招成算升一档（既稳又可能加分，全局最划算）。「循史」结局史评有下限 35。

## 四、体魄、年龄与寿元

章首按年龄扣体魄，但体魄高老得慢（这就是「寿元」）。寿元由当前体魄推出，不用存。一句话：**体魄是折寿额度**，前期少花，后期才扛得住衰减值。

| 剧本 | 起始 | 衰老扣体魄（档） | 寿元（折寿点） |
|---|---|---|---|
| 李斯 | 25 | 55+−2 / 65+−4 / 76+−6 | 体魄≥35 +1 · ≥48 +2 |
| 荆轲 | 30 | 35+−1 / 37+−2 | 体魄≥50 +1 · ≥60 +2 |
| 韩信 | 20 | 29+−1 / 32+−2 / 36+−3 | 体魄≥45 +1 · ≥58 +2 |
| 项羽 | 22 | 28+−1 / 31+−2 | 体魄≥65 +1 · ≥74 +2 |
| 陈胜 | 35 | 36+−1 / 37+−2 | 体魄≥41 +1 · ≥47 +2 |

## 五、疾病与那个看不见的「戒心」

- **染病概率** = 3% +（45−有效体魄）×0.4% +（有效年龄−55）×0.4%（上限 35%）；体魄好、年轻更不易病。五部药资均 3 财富，财富 ≤ 0 不能求医。
- 每个剧本有**隐藏值**（李斯「赵高暗流」、项羽「诸侯离心」等）：看不见数字，可当门槛（戒心须 ≤ N），第 3 章起给状态词，并决定致死时的结局变体。

| 剧本 | 隐藏值 | 初值 |
|---|---|---|
| 李斯 | 赵高（暗流） | 30 |
| 荆轲 | 秦王戒心 | 20 |
| 韩信 | 刘邦疑心 | 15 |
| 项羽 | 诸侯离心 | 15 |
| 陈胜 | 诸将离心 | 15 |

## 六、让选项变灰的隐藏门槛

除了属性门槛，还有叙事门槛：

| 门槛 | 含义 |
|---|---|
| flag / notflag | 需要 / 不需要某旗标 |
| minChapter | 章数下限 |
| devMin / devMax | 偏离度区间（太低或太高都锁） |
| weijiMax | 危机上限 |
| quanshiMax / junxinMax | 权势、君心硬上限 |
| zgMax | 隐藏值上限（戒心太高就锁） |

界面会写明原因，被锁不是 bug，是你还缺条件。**旗标**常一物三用：解锁钥匙 + 结局开关 + 触发章首暗账。

---

## 七、几个易漏的机制

- **蓄势**：下次事件抉择险招成算 +10（进新章清零），最实在的保命资源。
- **险招失败 = 选项烧毁 + 事件终结**，不是重来。
- **面板数字报实际生效值**，触顶只报真实涨点，不骗你。
- **硬核连卡面数字都抹掉**，只给「耗财 / 费力」。

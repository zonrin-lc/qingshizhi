# 《青史志》官方攻略 · 入门篇（3/6）：偏离度与评分——改写历史才是你的分数

> **《青史志》官方攻略 · 入门篇 第 3 篇 / 共 6 篇**
> 开发组继续。这篇是很多人第一次玩会误解的地方：**偏离度不是惩罚，是刻度，而且是你分数的主杠杆。**

## 偏离度：四档

偏离度是你「改写历史」的累计幅度，事件与行动卡都可能推高它。四档：

| 档位 | 偏离度上限 | 含义 |
|---|---|---|
| 循史 | ≤ 20 | 完整复刻了历史，连他的错误都没改 |
| 微澜 | ≤ 45 | 大势之内的小挣扎，只在字里行间留了几处批注 |
| 改流 | ≤ 70 | 走向开始变，史官的笔追不上了 |
| 逆天 | ≤ 100 | 无人见过的新历史 —— 无论结局如何，它属于你 |

三点要记住：

1. **偏离度不是惩罚，是刻度**。终局评分里「影响」一项 = 偏离度×0.6 + 功业×0.4 —— 想刷高分，偏离度是主杠杆。
2. **它决定终局尾声的语气**：≤20 是「你决定照抄一遍，这也是一种玩法」，≤45 是「史书没变，但多了几处批注」，再往上就是「史官的笔追不上你」。
3. **它也是结局准入条件**：部分结局带「偏离度上限」门槛，走得太偏或太保守都进不去。

## 终局评分怎么算

```
总分 = (功业×0.30 + 存续×0.30 + 史评×0.20 + 影响×0.20)
       × 难度系数 × (逆天结局 ×1.15) × 回溯惩罚
```

| 分项 | 怎么来的 | 能不能刷 |
|---|---|---|
| 功业 | 权势峰值×0.45 + 政绩×0.15 + 功业标记分 | **能** |
| 存续 | 结局自带的定义值（你活成了什么样） | **不能**（由路线决定） |
| 史评 | 50 + 史评原始分×0.5 + 史评加成 | 间接 |
| 影响 | 偏离度×0.6 + 功业×0.4 | **能**（偏离度是主杠杆） |

评级十档（分越高越好）：**甲上 95 / 甲 90 / 甲下 85 / 乙上 80 / 乙 70 / 乙下 60 / 丙上 50 / 丙 40 / 丙下 30 / 丁** 兜底（不足 30）。

两个要记住的点：

- **存续是唯一编码「结局性质」的维度**，它不由你刷——你走什么路线，才是什么活法。
- **逆天结局额外 ×1.15**。也就是说「改写历史」本身在评分里是加分的：偏离度不是惩罚。

## 二、偏离度四档与印章

| 档位 | 偏离度上限 | 含义 |
|---|---|---|
| 循史 | ≤ 20 | 完整复刻了历史,史书正文没变 |
| 微澜 | ≤ 45 | 大势之内的小挣扎,只在字里行间留批注 |
| 改流 | ≤ 70 | 开始改写走向,史官的笔追不上了 |
| 逆天 | ≤ 100 | 无人见过的新历史,无论结局如何都属于你 |

结局的「影响」分 = 偏离度×0.6 + 功业×0.4;偏离度还会决定终局尾声的三种语气,以及某些结局的准入门槛(`devMax`)。

印章共五色: 循史 / 苟活 / 稳健 / 逆天 / 败局 ——印章是**结局的性质**,不是分数:「苟活」与「败局」是活法不同,不是高低。

| 差距(还差几点) | 成算 | 备注 |

| 4–6 | 五成 |  |
| 7–9 | 四成 |  |
| 10–12 | 三成 |  |
| 13–15 | 两成 | 不建议赌 |
| ≥ 16 | 一成半 | 基本别赌 |

- 「史实」类选项(维持历史惯性)成算**升一档**(五成→七成、四成→五成……)。
- 掷 1–100 骰,点数 ≤ 成算即成。**险招失败,该选项当场烧毁**(本章此事件内不可再试),且失败即事件终结。
- 财富门槛默认是**硬门槛**(钱不够直接锁死,不是险招);硬核难度下卡面数字还会被抹成「耗财/费力」这类措辞。

## 四、终局评分与评级

总分 = (功业×0.30 + 存续×0.30 + 史评×0.20 + 影响×0.20) × 难度系数 × (逆天结局 ×1.15) × 回溯惩罚

| 分项 | 怎么来的 | 能刷吗 |
|---|---|---|
| 功业 | 权势峰值×0.45 + 政绩×0.15 + 功业标记分 | 能(权势/政绩/功业) |
| 存续 | 结局自带的定义值(这一结局代表你活成了什么样) | 不能(由路线决定) |
| 史评 | 50 + 史评原始分×0.5 + 史评加成 | 间接 |
| 影响 | 偏离度×0.6 + 功业×0.4 | 能(偏离度是主杠杆) |

评级十档(分越高越好):甲上 95 / 甲 90 / 甲下 85 / 乙上 80 / 乙 70 / 乙下 60 / 丙上 50 / 丙 40 / 丙下 30 / 丁 兜底。

> 每回溯一次,总分系数 ×0.98(回溯是后悔药,药钱按次扣)。
> 通关下一部剧本的门槛:上一部达成**乙级及以上** + 解锁 **3 个不同结局**。

## 六、一回合的结构

- 每回合发 **4 张**:1 张关键事件卡(限时 3 回合,倒计时归零强制进事件页)+ 3 张行动卡。
- 关键事件卡不占牌位,它以提示条形式出现,点它进入事件抉择。
- **抉择卡**每两轮强制占一个发牌位(整局一张只发一次);染病时多一张「求医问药」(占一个牌位,财富 ≤ 0 时不得求医)。
- 行动池按本章过滤;**硬门槛不达直接不出现**,软门槛不足则带 ⚠ 险招徽章入列。
- 同一张行动卡**可以反复打**:引擎有「重复使用收益递减」规则(`ACTION_RULES.diminish`),但五本剧本当前都把它关掉了(`diminish: false`),所以收益不打折。
- 抉择卡落定后整局不再发。

## 七、危机与死亡

- 危机(weiji)满 100:致命难度**直接死**;非致命难度钳到 **95**,回落会单列一条「危机封顶回落」结算条目。
- 染病时体魄归零也可能死(致命难度);非致命难度体魄最低留 1。
- 每章有 2–3 个危机事件;危机 70–89 时本章会额外插入一次构陷际遇。

## 八、际遇与历史修正

- **际遇**:每回合 40% 概率触发,每章至多 2 次(各剧本可用 ENCOUNTER 覆写)。本游戏共 60 条,分布:李斯 · 仓鼠之局 12 / 荆轲 · 图穷之局 12 / 韩信 · 兵仙之局 12 / 项羽 · 霸王之局 12 / 陈胜 · 首义之局 12。
- **历史修正**:章末掷一次骰,按高/中/低三档决定是否触发一条修正(共 45 条)。修正会改写本章的历史,通常伴随偏离度与属性变化。

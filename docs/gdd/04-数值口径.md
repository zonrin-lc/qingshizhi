## 4.2 四维完整计算式

**功业** = clamp(权势峰值×0.6 + 事功分, 0, 100);事功分=Σ 逐项对照表值(未命中走剧本显式默认处理)。输入=权势历史峰值、事功标记累计。
**存续** = 所落结局声明的存续基准分(无过程修正)。输入=结局格。
**史评** = clamp(50 + 历史分×0.5 + 旗标加成, 0, 100);印章=循史时史评≥35。输入=历史分(选项声明逐次累加,可负)、史评加成旗标、印章。
**影响** = clamp(偏离度×0.6 + 功业×0.4, 0, 100)。输入=偏离度、功业。
**合成** = 0.35×功业 + 0.25×存续 + 0.20×史评 + 0.20×影响(四维满格→合成恒=100)。

截断规则:四维一律截断到 0–100;合成值天然≤100;总分可破百(仅来自系数)。

## 4.3 三档难度完整系数表与体验描述

| | 危机系数 | 修正危机系数 | 总分系数 | 回溯 | 致死(危机≥100) | 属性/成功率显示 |
|---|---|---|---|---|---|---|
| 剧情 | 0.6 | 0.5 | 0.8 | 无限 | 否(100=封顶线,每章仍强制构陷直至降下) | 全数值+最终率 |
| 普通 | 1.0 | 1.0 | 1.0 | 每章一次 | 是 | 全数值+最终率 |
| 硬核 | 1.2 | 1.3 | 1.25 | 无 | 是(即死) | 档位词(无数字) |

体验一句话:剧情=音量拧到六成、死不了人、随便回头,但总分恒八折,不走逆天评级天花板乙上;普通=全额世界,标准 60–90 分,每次后悔折 2%;硬核=四重代价换全局最高系数,合成 70 即甲下、可破百。
作用域纪律:危机系数与修正危机系数为**并行两条通路,不叠乘**;难度不得覆盖五列(全局锁定,保跨剧本评级可比);难度只调"承受",险招赔率全局单值不动。

## 4.4 回溯衰减曲线

`回溯系数 = 0.98^k`(k=回溯次数;硬核恒 k=0)。参考刻度(0.98^k):k=5→0.90、k=10→0.82、k=20→0.67、k=35→0.49。
举例(剧情,合成 100 时):k=0→80(A)、k=5→72.3(A)、k=10→65.4(B)、k=20→53.4(C)、k=35→39.5(D)。
**为什么永不为零**:0.98^k 无限趋零、永不到零——惩罚做成斜率而不做成断头台;玩家在任何时刻都保留"这一局还值得打完"的资格。不设下限,只设价格;停不停手玩家自己算——与"反噬是账单不是天罚"同一笔法。

## 4.5 系数咬合:分数里有多少来自选择,多少来自选了哪档

管线:`行局 → 合成[0,100] → ×难度 ×1.15^(是否逆天) ×0.98^k → 评级`。
同一合成值(如 100)的读数表:

| 组合 | 总分 | 评级 |
|---|---|---|
| 剧情无逆天 | 80 | A |
| 剧情+逆天 | 92 | S |
| 普通无逆天 | 100 | S |
| 普通+逆天 | 115 | S |
| 硬核无逆天 | 125 | S |
| 硬核+逆天 | 143.75 | S |

够 S 所需合成值:硬核+逆天 59.1 < 硬核无逆天 68 < 普通+逆天 73.9 < 普通无逆天 85 < 剧情+逆天 92.4 < 剧情无逆天(不可能,需 106)。
**诚实拆分(天花板局 143.75)**:合成贡献≈100=**70%**(行局表现);总分系数≈25=**17%**(开局点"硬核"那一下即定,唯一不是局内表现的部分);逆天系数≈**13%**(轨迹溢价:需偏离≥71 并活着落格,而偏离已经先经影响六折进过一次分——同一根轴,系统明码标了两次价)。剧情玩家则被结构性折价 20% 并随回溯持续放血。骰运不进分但改轨迹:烧毁烧掉的是事功与未来的旗标路径,运气经"选择被现实纠正"间接改写那 70% 的内容。
结论:评级=表现×你为自己选的处境,且处境部分全有价目表可查。

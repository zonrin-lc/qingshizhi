# 07 · 界面与美术

> 本章读者:评审与后来的开发者。判定标准不是"好不好看",而是**这套界面在替机制做什么**。本章专用纪律:每条界面规则必须回答"服务于哪条设计、约束了机制什么";纯装饰性描述一律移入 §2 美术规范,本章不保留。

## 7.2 视觉规范

**色板**(水墨宣纸底+朱砂点睛,全部色值以语义命名入配置表):
| 语义 | 用途 | 规则 |
|---|---|---|
| 玄墨底 | 全局背景 | 永不做插画化背景——背景越静,弹幕越可读 |
| 宣纸层 | 卡片/面板底 | 三档明度:卡<面板<浮层,建立 z 序而不靠阴影堆 |
| 朱 | 印章、关键卡卡背、**赤色描边(构陷/反噬专属)** | 赤色描边=乙类接管的唯一视觉词,全局不复用 |
| 青 | 「史」字标记、史实升档提示 | 与朱严格分域:青=史书,朱=危机 |
| 金 | 成就、逆天段、S/A 评级 | 奖励色系,永不用于惩罚信息 |
| 墨 | 正文/标题 | 正文主色 |
| 灰阶 | 锁定项、禁用、未解锁 | 灰置+原因文字=硬门槛的固定表达 |

**字号层级(5 档,全界面统一)**:题(章首旁白首行/结局名)>段(叙事正文)>标(选项标题/面板维度名)>注(结算文本/弹幕/词条)>微(辅助计数、版本号)。规则:同一屏不超过 3 档;**弹幕只用注级**,字号不再分级——反馈靠色与动效,不靠大小抢戏。
**间距体系**:4 的倍数阶梯(4/8/12/16/24/32),卡片内边距固定一档;选项行高=标级字高×2.4(保证拇指热区)。
**徽标体系(全局仅五枚图形记号,其余一律文字)**:「史」(青)/ 赤描边(乙类接管标记)/ 段位名印(循史/微澜/改流/逆天四字制式,顶栏常驻)/ **印章五枚制式**(循史·苟活·稳健·逆天·败局,朱文方印形态,**图形+文字双编码**)/ 评级字母(S/A/B/C/D)。

## 7.3 朝代选择器 · 完整交互规格

**形态**:横向卷轴年代轴;轴上为朝代节点(按年代排序),每个朝代节点下挂剧本卡(本朝无剧本则节点不出)。

| 子项 | 规格 |
|---|---|
| 拖动 | 单指横向跟手,位移 1:1 映射年代轴;越界带橡皮筋回弹(最大越界 48px) |
| 吸附 | 释放瞬间对**速度**取预测落点后吸附到最近朝代节点;吸附动画 320ms,缓出曲线;吸附完成轻震(平台支持时) |
| 阻尼 | 接近两端未开放区时摩擦系数渐增(越靠近边界拖得越沉),明示"时间线到尽头了"——不用弹墙,用变重 |
| 朱印 | 选中朝代节点盖朱印(印起=该朝代展开);朱印是**当前态的唯一指示** |
| 刻度 | 年代轴每节点刻干支/帝号简写,每朝一段总刻度 |
| **年代线** | 独立指针(区别于朱印):标记玩家**已完成最深**的朝代——"你的历史走到哪了" |
| **朱印与年代线关系** | 朱印=正在选(瞬时),年代线=已经过(持久)。玩家拖过未开放区时,**年代线纹丝不动**——这条分离是防误导的核心:指针只跟随历史事实,不跟随手指 |
| 年代线联动 | 选中朝代展开剧本卡;首次完成任一本→年代线推进一步+全局轻提示一次,之后不再 |
| 未开放朝代 | **按 05 5.2.7 裁定"建议先通"为路径引导非权限门:未开放不锁、不隐**,仅以低一档墨色弱化+无剧本卡时不出卡。不出现锁形图标 |
| 同步纪律 | 进入选择器时朱印落在"上次退出的朝代",年代线恒在历史位置;两者重叠时(玩家回到已通朝代)朱印套在年代线上,朱色压墨色——**界面直接讲出"你回到了你已经走过的历史"** |

**本章专用检查**:① 年代线不可被滑动操作直接移动——机制上"历史进度"唯一写入方是结局判定;② 未开放区可拖入可回看(引导不惩罚),但剧本详情卡仅对已开放本展开。

## 7.4 可读性与可玩性:书法字体的风险与处理(已确立=全局书法)

**已确立设定:本作全文统一使用书法字体**(该项先于本章确立;本章初稿曾提"展示层书法、阅读层宋/黑体"的分层方案,因与既定冲突,**降级为提案 P-7 移入附录 A**,正文按全局书法书写)。

**风险(全局书法自担)**:行草字形对无古文训练者不可读;长文疲劳;而 R2 逐句渐显、R9 完整呈现要求玩家**读完**——字形读不动,铁律被字体打折。

**处理(全部兼容于全局书法,不改用字)**:
1. **朗读同步逐句高亮**:配音(R6)与叙事区行高亮随音推进——读不动,可以听;
2. **异体字/通假字自动挂词条标记**(C7 延伸):不读即不识,不识由词条补课——书法的"读不动"降级为"不认识",而"不认识"恰是词条系统的本职;
3. **篇幅纪律托底**:叙事段≤3 段、长结算 61–100 字仅节点专用(C10 分级)——用文字密度限保住书法的可读下限;
4. **档位词取最高易辨字面**:词义模糊是设计,字形模糊是事故,两者不得叠加(此句为 P-7 提案的核心论据;全局书法下现以字面选择兑现)。

**提案 P-7(待裁定,正文不生效)**:按文本层分级用字——展示层(标题/印章/段名/史传)书法,阅读层(旁白/选项/结算/词条)宋/明体,数值层系统黑体。收益:R9 的阅读层不再依赖语音辅助;代价:视觉统一性断裂、须正式重裁"全局书法"既定。**两案不并存:定了再同步前文。**

## 7.6 这套美术方向如何为「涌现」服务

不讲"水墨有历史感",只讲哪条视觉决策在替机制做事、替它省下哪一次解释:

1. **段位用色阶不用数字**:偏离度顶栏条按段变色(墨→青→赭→朱)——"世界用四种脸看你"必须一眼可辨,不需要读 0–100 的数;且**不可逆性由色彩记忆承担**(从朱回不到墨,色阶在替时间之箭说话)。数字只进结算页,颜色常驻视野。
2. **赤描边全局只留给乙类接管**:玩家学会"红边=题被换掉"只要一次;青只留给「史」,金只留给成就——**五枚记号的全局不复用,就是把"机制可学习"写进颜色**。涌现要可玩,前提是规则信号不串台。
3. **印章五枚制式=封闭词表的视觉固化**:朱文方印是史书定评的图形语言;五枚印、图形+文字双编码——**评级的"定性有限集"与四维的"定量连续"在画面上直接分层**,玩家看见印就知道"这是盖棺的,不是打分的"。
4. **史传断语体+书法**:盖棺的体裁配盖棺的字——书法用在"论"上(史传、印、节点名),印刷体用在"事"上(选项、结算);**字体的分工即涌现叙事的分工:事是系统算的,论是史官写的**。
5. **弹幕不阻塞**:R3 规定反馈是飘字不是弹窗——**世界先记账、不打断你翻书**,对弈的手感靠的是"落子声轻、棋谱不断"。
6. **年代线只跟随历史**:指针不可拖、只被结局推进——选择器在教玩家一件事:**进度不是位置,是走过的历史**。

一句话:**本章全部视觉规则的共同取向——让信号的语义密度最大化,让解释的文字量最小化;涌现要被人"看懂为自己的因果",靠的就是这些不解释的记号。**

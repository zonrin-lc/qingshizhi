# 【聚光灯21天】DAY 3-4 · 把"历史惯性"做成一个能计算、能博弈的数字

![核心循环](workspace://assets/images/devlog/day34-loop.png)

前两天的轨迹:主题拆解 → 五丈原原型 + 批量模拟验证 → 判定"片段太薄" → 转向**多剧本设计**。这两天完成了方向落地与大部分系统设计,游戏定名《青史生存录》(10.5 已裁定更名《青史志》,本稿为冻结快照不追改),载体改为零依赖 HTML5+JS,手机浏览器即开即玩。

## 概念(一句话)

> 重生历史人物,从第一道岔口起,你的每次选择都在对抗历史惯性:顺之者安,逆之者险。

首发五剧本:李斯、荆轲、韩信、项羽、陈胜。史实不是布景也不是笼子,是**对手盘**——它给参照(选项上的"史"字标记),也给反噬。

## 本作核心创新:偏离度——一个数字,双重身份

![偏离度](workspace://assets/images/devlog/day34-deviation.png)

设计主张:**把"历史的重量"从文案搬进规则**——惯性必须能被看见、被计算、被博弈,而不是被旁白宣告。

- **0–100,全局唯一,只增不减**,负增量无效、引擎直接丢弃;
- **四段位:循史 / 微澜 / 改流 / 逆天**,顶部指示条按段位变色;
- 它量的不是"剧情进度",是**历史对玩家预测的失效程度**:循史段世界还猜得透你,逆天段你面对的已经不是"历史",是"局势";
- 双重身份:**压力来源**(段位越高,章末"历史修正"越重)× **资格门槛**(每个结局声明可用的偏离度区间——越偏,能走的门越少)。痛与奖是同一把尺,因为"你偏了多少"和"你能回哪去"在历史的逻辑里本就是同一个事实的两面。

关键细节:**增量为 0 是常态**。大量顺从史实的选择就是 0 增量——循史不是默认值,是玩家每一手主动维持的姿态。

两个想通了就觉得"对"的点:

- **历史修正是遭遇,也是一张账单。** 一条修正 = 一段遭遇文本 + 一组负向属性变动(减名声、减君心、减权势、增危机)。文本是"它怎么发生",变动是"它在你身上留下什么"——只给文本不给数值,修正是故事;只给数值不给文本,修正是税。而且它没有正向:五个剧本的修正池里,正向条目为零,它永远站在你对面。
- **只增不减是设计代价,不是缺陷。** 可回滚的"偏"不叫对抗惯性,叫和历史做买卖。它是全作唯一的时间之箭——属性可攒、际遇可躲,唯独不可逆这件事不可商量。后悔的出口在 meta 层(复盘重开),不在局内。

## 玩法循环(宏观)

主页→朝代→剧本→难度,进入后按章推进(李斯 7 章,含序章)。每回合发 4 张牌:**关键事件卡×1 + 普通行动卡×3**。关键卡倒计时 3(单位是"打出的行动卡"),归零**自动开启抉择页,必须亲自选**;章末结算 = 属性面板 + 偏离度变化 + 历史修正判定。

![关键卡](workspace://assets/images/devlog/day34-card.png)

设计浓度最高的是关键卡的**不预告**:倒计时期间只显示"再打出 N 张后开启",不显示事件内容。于是玩家对"以什么姿态撞上节点"是盲的——他知道有个劫要来,不知道是什么劫,**只能按最坏情况准备**。"准备"失去信息支撑,行动卡从"刷属性"变成"押注"。惯性的两副面孔就此完整:偏离度管你偏了多远,倒计时管你蒙眼撞上的姿态。

行动卡则回答另一个问题:**为什么同一事件,历史中的人做了 A,你偏要做 B?** 每条路线都需要"先配得上"。同一行动同一章第 n 次使用收益按 ÷2^(n-1) 递减、**代价项不减**——净边际收益必然转负,任何一张卡都刷不出无脑循环。代价恒定的意义是:资源门槛是真门槛,不是会通胀的名义价格。

## 险招:给"我以为我够格"标价的六档阶梯

![险招](workspace://assets/images/devlog/day34-risk.png)

不达标选项不禁选、不白给,**按差值定价掷骰**(70% 起步一路跌到 15%),掷骰走独立随机流;失败则选项**烧毁**——烧掉的是做法不是路,疤留在菜单上,下一题你绕着走。顺从史实的选项再升一档,但封顶 70%:连照史书做都不担保,系统对玩家和对史书上那个人,用同一副骰子。

70→50 那个 20 点的断崖是故意的——它专治"就差 3 点,应该没问题"的错觉。**软门槛可赌,硬门槛免谈**(能力差一点可以拼命,处境不对没有骰子)——这条分界也给了剧本文本"强人所难"的正当性。

## 其他定稿

- **十一维属性**:自身(体魄/武力/文才/谋略/辩才)管开门,身外(财富/名声/权势/政绩/君心/危机)管结果;初始值即人格——第一眼读出的不是数字,是这个人的来路。
- **五条独立随机流分离**(骰子 / 事件 / 抽卡 / 际遇 / 修正):任何一条流的推进不改变其他四条的序列——玩家回档重试时看到的是同一个世界,不是换了一套游戏。
- **交互铁律【结算必须先于叙事推进】**,点击后 0.5 秒内必见结果——这不是 UI 规范,是卖点"每个决定立即有回响"能否兑现的前提。
- **三难度**:剧情 / 普通 / 硬核。硬核的核心差异是信息不是数值——属性和成功率都只给档位词,无存档;回溯恢复历史状态,但不恢复随机命运。
- **零依赖 HTML5+JS**:单 HTML 文件、无构建、无网络请求,手机浏览器直开,也支持 PC。
- 五剧本 34 章 104 个关键事件的章节骨架与数值总表已排出——剧本包从"写故事"变成了"填表"。

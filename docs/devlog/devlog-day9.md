## 一行残留,和它暴露的系统性漏洞

根因小得可笑。重构 `renderSide` 时,我删掉了开头的:

```lua
local side = env.sideCol     ← 删了
```

但函数**末尾**还留着:

```lua
side:AddChild(panel)          ← 没删
```

`side` 于是成了**未定义的全局变量**(值是 `nil`),一进对局页就炸。

**真正值得记的不是这个 bug,是它为什么一路绿灯到了真机:**

| 闸口 | 能不能拦住 | 为什么 |
|---|---|---|
| 语法检查(编译) | ❌ | `side:AddChild(panel)` 语法**完全合法** |
| API 检查 | ❌ | 只查 `T.*` 符号存在性,不查局部变量泄漏 |
| 构建 | ❌ | 构建也只做语法检查 |

**三道关全过,只有真跑起来才炸。** 这类"删了声明、留了引用"的错误,静态检查天然抓不到——除非专门为它写一条规则。

## 第三道闸:抓"裸全局名"

于是给 API 检查加了一条规则:**找出"被当表/方法用、却从未声明为 local,也不在引擎全局表里"的标识符**。

设计上有个关键取舍:**引擎全局名不手工维护**。我从 `.emmylua/*.d.lua`(引擎的类型定义)**自动派生**出 **1784 个**全局名——引擎加接口,检查自动跟上,白名单永不过期。

规则只抓**"当表用"**:

```lua
side:AddChild(panel)   ← 报(side 是 nil,访问必崩)
x = side               ← 不报(单纯引用,nil 也不崩)
```

第一版误报 34 条,全是 `math` / `function` / `self` 这类。逐个收干净后:

| 步骤 | 结果 |
|---|---|
| 注入 bug(把 `body` 改回 `side`) | `FAIL game.lua:150 裸全局名 'side' 当表用` ✅ |
| 恢复 | `API CHECK OK` |

顺带把扫描范围从 `ui/` **扩到整个 `qingshi/`**(跳过生成的大数据文件),`engine.lua`、`store.lua` 也进了检查。

**三道闸现在是:**

| 工具 | 抓什么 |
|---|---|
| 语法检查 | 编译不过 |
| **API 检查** | 符号不存在 + 优先级陷阱 + **裸全局名**(新) |
| 100 局对拍 | 逻辑跑偏 |

## 一个不体面的发现:我把"规范"做成了"原型图"

下午转做设计。先出了一版对局页效果图,你说**"设计感少了太多,看起来像原型图了"**。

回头看,这话说得准。我错在:**把 prompt 写成了规格说明书**——逐条 px 值、逐条对齐要求。AI 于是照着画了一张**规格图**:边距对、圆角对、基线对,**但整张画面是平的**。

规范只约束了**几何**(边距/圆角/对齐),**没约束材质**(纸纹/墨晕/木色)。于是"对齐"成了唯一目标,**网格纪律变成了扁平化**。

重做时加回**材质层**:

| 手法 | 具体 |
|---|---|
| 材质 | 宣纸纤维纹理 + 米色晕染,不是纯色块 |
| 卷轴形制 | 两侧深木轴头、**双线金框**、四角**云纹角饰** |
| 立绘融合 | 淡墨写意收边,**没有硬边方框** |
| 书法 | 事件标题用行楷,配朱红起首印 |
| 分隔线 | 不是裸线,而是「金线 + **中央嵌菱饰**」 |

**记一条纪律:规范管几何,材质给温度,两者不冲突。**

## 一个不是我的 bug

预览日志里一直有一条:

```
ERROR: ... 'LuaScripts/Utilities/Previews/Isolation_Client':
       :186: attempt to index a nil value (local 'class')
```

我扒开引擎那个 **94MB 的 `.data` 包**,找出模块源码。第 186 行是 `local orig = class[methodName]`——**传进来的 `class` 是 nil**。

决定性的是**引擎自己写得不一致**:同一份代码里,兄弟函数 `BlockMethod` / `BlockProperty` / `RemoveMethods` **全都有** `if not class then return end` 守卫,**唯独 `WrapPathMethod` 漏了**。引擎作者明确知道"类可能是 nil",只是忘了这一个。

又查了当天刚发布的 `latest` 引擎版本——**同一行一字不差,仍无守卫**。升级修不好,**只能报给引擎侧,修法是一行**。

而我们这边其实没受影响:日志显示报错之后 110 毫秒就是自己的启动输出——引擎用 `pcall` 兜住了。**一个不崩的 bug,连引擎自己都不打算崩。**

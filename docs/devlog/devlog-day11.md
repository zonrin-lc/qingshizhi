### 缺口从哪来

游戏里"出场角色"就是正文里被 `⟦⟧` 包裹的名字——`currentSpeaker` 靠它决定右栏显示谁的立绘。所以缺口清单可以**从剧本里算出来**:

```python
# portraits-gap.py
HAVE = 解析 game.lua 的 CHAR_IMG      # 已有立绘的角色
NOT_PERSON = { 地名/官名/器物/制度… }  # ⟦⟧ 里混的非人物词,显式列出
gap = ⟦⟧ 词 − HAVE − NOT_PERSON       # 剩下的就是待补人物
```

结果:**`⟦⟧` 词 141 个 = 有图 70 + 非人物 71 + 待补 0**。

`HAVE` 一开始是**手写的中文名表**,和 `CHAR_IMG` 是两份数据——立刻就不一致了。改成**直接解析 `game.lua`**,以后加角色只改一处。

### 抠图流水线

生图是**宣纸底**(带纸纹、远山、朱印、题字),不能直接用。流程:

```
生成 512×768 宣纸底
  → AI 逐张抠图(去掉纸底/远山/朱印/题字,保留飞白枯笔)
  → 归位脚本校验(尺寸必须 512×768,透明占比需合理)
  → char_<拼音>.png
```

**为什么不用算法抠图**:水墨人像的边缘是**渐变**的(飞白、枯笔),没有清晰边界。洪水填充在低阈值留一圈墨晕、高阈值把人咬缺,**两头都不对**。逐张 AI 抠图是目前唯一稳定的办法。

## 审校:风格统一 ≠ 不雷同

72 张做完,我请自己做了一轮**全量设计审校**——找"过于雷同"和"偏离风格"的。

结论出乎意料:**风格统一性完全达标,但姿态雷同严重。**

| 群组 | 情况 |
|---|---|
| 拱手/拢袖 | 8 张**几乎同款**(侯公与田光剪影 IoU **0.89**) |
| 执卷文臣 | 10 张里 **9 张同款**(李斯与姚贾 IoU **0.90**) |

**约 17/72 张(24%)落在两种重复姿态里。**

还有三处离群:
- **尺度**:张良 91%、漂母 93%、孔鲋 95% —— 立绘列是**底对齐**的,高度差会直接表现成"忽大忽小"
- **元素**:张良手持**羽扇** —— 羽扇是明清诸葛亮的符号,放在秦末汉初是**时代错位**
- **抠图**:范增等 3 张半透明像素占比偏高,边缘有淡灰雾

### 一个失效的指标

我写了个量化审校脚本,想用**剪影 IoU**(两张图 alpha 轮廓的交并比)自动找雷同。结果:

**所有 72 张两两 IoU 都在 0.88 以上。** 指标完全失去区分度。

原因:所有立绘都**裁得很满**(人物高度占比中位 **99%**),底色又都是同一纸感——残差主要来自"填满画幅"这个**共性**,而不是差异。

> **教训:一个度量如果测的是"所有人的共同点",它就找不出离群者。**
>
> 我后来改成:**指标只用来筛可疑,结论一律目视复核。** 最后那对 滕公↔李左车(0.86),是拼图放大、确认"银灰斗篷+马缰 vs 蓝袍执简"一眼可分之后才判通过的。

## 今天最值钱的一条

**风格统一和构图不雷同,是两件事。**

前九天我一直在追"画风统一"——都水墨、都宣纸底、都半身胸像。今天 72 张摆在面前才发现:**画风统一做到极致,反而暴露了构图的高度同质。** 而且这种同质,**肉眼看单张完全看不出来**——必须把它们**拼在一起横比**才显形。

同样地,想用**一个数字**(IoU)把这件事自动化,也失败了:测"共同点"的指标测不出"离群者"。

**结论:批量产出的东西,审校方式必须跟着变——从"逐张看"改成"成组比",从"看单张质量"改成"看组内差异"。**

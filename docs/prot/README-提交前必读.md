## 为什么是调整，不是替换

有人问过：能不能直接拿工程参考文档替换这份投稿稿。**不能。** 理由：

| | 投稿版（本目录） | 工程参考文档 v0.9 |
|---|---|---|
| 定位 | 面向读者与评审，讲清设计意图与体验逻辑 | 逐条对着实现写的口径级文档 |
| 组织 | 三十一章设计叙事 + 主题对齐 + 赛期交付 | 正文一章详录一个剧本，其余四本散在附录 |
| 篇幅 | 评审读得完 | 18 万字，附录 A–S 逐条记录修订史，读完等于没读 |
| 主题呼应 | 有专章论证与「涌现」的对应 | 无 |
| 交付内容 | 含开发日志规划与投稿物料 | 无 |

替换的结果是一份没人读得完的文档。**两份都要：投稿用这份，实现口径看 v0.9。**

冲突时的裁决规则已写进本文档总纲第一条：实现层面听 v0.9，设计意图层面听投稿版。

## 本轮调整了什么

原稿由 AI 在独立沙箱中写成，二十余章全部凭空推演——它看不到仓库，于是把所有具体事实锁进「待核清单」，等有人填。填的人是这一轮。

| 项 | 原稿 | 现稿 | 依据 |
|---|---|---|---|
| 事件总数 | 119 | **117** | 五剧本章节树内事件标识去重计数 |
| 工程参考文档 | 「工作区未见」 | 已归位并逐条核对 | 文件存在，18 万字节 |
| 静态校验 | 提案 | **已实装**，9.3 已标注 | 键与路由静态扫描套件实跑 |
| 回归套件 | 七套 | **八套** | 含静态扫描套件 |
| 断言数 | 336 | **446，全绿** | 八套实跑合计 |
| 待核项 | 20 项待填 | **填入 12 项** | T-01/04/05/06/07/08/09/10、V-05/07/09 |
| 随机流可注入性 | 待核 | **五条全部可注入** | 引擎按名支持常量生成器 |
| 印章命名债 | 待锚定 | 已在册，校验已覆盖 | 静态校验实跑 |
| 排期表前提 | 「代码在哪」为第一待核 | 已核实并关闭 | 见附录 C |

保留待核的是**只有主办方能回答的**：投稿通道对提交物的格式与体积要求、兼容矩阵的判定结论、有效试玩的计数口径。这些不该由设计文档猜。

## 新增附录 C 的内容

原稿最缺的不是设计，是**证据**。附录 C 是这一轮对照实现逐项核出的证据层：

- 内容骨架：五剧本的章数、事件数、选项数、结局数、主敌类型
- 回归与校验：八套件、446 断言、静态校验已实装的五类职责
- 五条随机流的注入能力（这是「可重放」与全部观测项成立的技术前提）
- 存储四规则：存档分区、硬核不写、回溯清什么、坏档拒收
- **资产体积构成与处置建议** —— 见下
- 版本关系：应用版本与 GDD 修订史是两套编号，不对应也不需要对应

## 提交前必须处理的两件事

### 一、游戏名已统一为《青史志》（已完成）

浏览器标题、分享卡、下载文件名、朝代页与剧本页标题、五份剧本数据、引擎、软著申请材料（四份）、工程参考文档文件名，全部已统一。

旧横排标题图是位图、五字旧名烧在像素里，改名后无法文本替换；另两张新名稿为暗色试作稿、压在深色背景上看不清而未采用。**v2.1.5 起标题改为程序渲染文字**（横排金色／朝代页墨色），待合格位图交付后改回图片仅需一行。已登记为美术待交付项。

全仓残留旧名 6 处，全部是**应当保留的历史说明**——设计文档的改名记录、美术清单的改名说明、代码注释中解释「旧图内含旧名五字」的那句，以及软著源程序文档中逐字引用的同一句。替换它们反而会让记录失效。

### 二、资产体积 107.7 MB

首屏资源约 2 MB 量级，三十秒可玩成立。但完整通关需拉全量，且体积结构里有明显可裁项：

| 处置 | 立省 | 风险 |
|---|---|---|
| 删除生成中间产物目录（9.7 MB） | 9.7 MB | 零 |
| 字体只留压缩格式，去掉后备格式 | 4.5 MB | 极低 |
| 成就图标重压（120 枚现共 30.7 MB） | 可望 20 MB+ | 低 |
| 立绘按需加载 | 视加载策略 | 中 |

前两项做完约 93 MB，第三、四项做完可到 50 MB 以内。**建议投稿前实测一次完整通关的实际下载量再定取舍。**

### 三、开发日志是硬门槛，与游戏做得好不好无关

有效投稿四条件之一：开发期内累计发布五篇及以上开发者日志，不能一天内连发，每篇至少一张开发过程截图，须加指定标签，空洞灌水不计数。

**附录 B 那四十余条推翻档案是最好的素材** —— 它记录的是「我编错了 → 被抓住 → 改掉」，这种东西没法伪造，也没法批量生产。它比任何「我们做了什么」都更符合评审对「真实记录」的要求。10.5 节已经给了组织法。

# GDD:《上蔡叹》—— 李斯 · 命运模拟

> 版本 v0.1 | 2026-10-02 | 状态:设计稿(未实现)
> 主题:涌现 × 历史扮演 —— 玩家扮演李斯,重走从"上蔡布衣"到"具五刑出咸阳东门"的一生。

---

## 1. 一句话定位

**《上蔡叹》是一款"一生尺度"的涌现型历史抉择游戏:**
每个选择只扰动若干人生变量,变量间反馈回路 + 历史时钟自动推演,四十年前的伏笔在沙丘之夜延迟兑现。玩家追问的不再是"怎么打这一仗",而是——**史实里那个贪恋禄位的李斯,有没有可能在那个晚上有别的路?如果有,需要他此前一生怎么做?**

## 2. 设计支柱

| 支柱 | 含义 | 对立面(避免什么) |
|---|---|---|
| **一生尺度** | 6 个阶段、约 24 回合、40 年跨度(前247入秦 → 前208腰斩) | 避免只有一场战役的片段感 |
| **延迟兑现** | 早年抉择写入伏笔,在终局(沙丘)集中清算 | 避免"选择↔结局"的分支树 |
| **筹码涌现** | 终局选项集由状态动态决定,不是预设分支 | 避免玩家以为"选就行",实际是"攒够了才有得选" |
| **双线结局** | 个人命运 × 秦室国祚 正交 | 避免单一胜利条件 |
| **史书自生长** | 每局结束汇编文言编年 + 太史公评语 | 避免结局只有一句文本 |

## 3. 命运引擎(人物无关,从蜀汉原型抽象)

### 3.1 状态变量(李斯包配置,0-100)

| 变量 | 含义 | 方向 | 终局权重 |
|---|---|---|---|
| `favor` 宠信 | 帝王对你的依赖 | good | 沙丘话语权 |
| `name` 名节 | 士林清议、身后名声 | good | 翻盘号召力 |
| `law` 治道 | 国家机器质量(郡县/文书/法度是否得人心) | good | 秦祚暗线 |
| `ties` 党援 | 朝中羽翼:蒙恬-扶苏一系、六国遗士、宗室 | good | **沙丘选项集的门票** |
| `greed` 权欲 | 恋栈禄位、自保私心 | bad | 附赵高的引力 |
| `age` 年齿 | 生命时钟(反着走) | bad | 善终/暴毙 |

### 3.2 隐变量:国祚 `fate_qin`

不在 HUD 显示。由 `law`、民心伏笔、六国遗恨累积,决定终局"秦会不会二世而亡"。个人命运与国祚**正交**——你可以善终而秦仍亡(独善其身),也可以族诛而秦祚延(用死换扶苏立)。这是本作最重要的涌现质感:**好人未必好报,坏局未必无解。**

### 3.3 反馈回路(数据驱动,回合末自动结算)

```
R1 宠信>70 且 名节<35   → 帝侧近竖臣(赵高)觊觎,党援被侵蚀
R2 名节<30              → 清议沸然,六国遗士离心,伏笔 flag: 遗恨
R3 治道>65              → 法度行而民安,国祚暗线 +
R4 治道<35 且 宠信>60   → 上侈下疲,国祚暗线 --(焚书坑儒路线的宏观代价)
R5 党援<25              → 朝中孤立 → 终局沙丘夜只剩"从"与"死"两个选项
R6 权欲>65              → 每逢大事,自保选项的"效果虚标"+5(诱惑加成)
R7 年齿>75              → 精力衰,事件池里"隐退/交权"事件强制出现
```

### 3.4 历史时钟与硬锚点

- 每回合约 1-3 年,阶段推进由年代触发。
- **不可改锚点**:始皇三十一年东巡、三十七年死于沙丘(游戏不扮演始皇,他的死是物理常数)。
- **涌现锚点**:谏逐客令(前237)、焚书之议(前213)、沙丘之变(前210)按年代强制入场;但每个锚点的**应对选项集**由状态裁剪。

### 3.5 终局选项集的动态生成(核心机制)

沙丘之夜事件不是四选一预设,而是:

```
基础选项: A 附赵高(改诏,立胡亥)     —— 永远在场
状态解锁: B 拒赵高而秘不发丧          —— 需 favor ≥ 55
状态解锁: C 联蒙恬、奉扶苏讨逆         —— 需 ties ≥ 45 且 曾与蒙恬善(flag)
状态解锁: D 以死相争于帐中,守先帝诏    —— 需 name ≥ 50 且 greed ≤ 40
```

选 C 的局:翻盘成败再由状态过阈值判定(类似五丈原会战公式),**不是选了就能赢**。
→ 设计意图:史实"李斯贪禄附赵高"不是剧本强制,而是他一生攒出的状态的自然出口;玩家若能让 C 亮起来,才算真正"改命"。

## 4. 人物弧线:6 阶段 26 事件(草案)

**S1 上蔡·荀门(前247前)** 3事件:厕鼠仓鼠之叹(定初始倾向)、师从荀卿(择"帝王之术"还是"王道")、离楚入秦抉择。
→ 伏笔:`greed` 底色、名节出身。

**S2 吕府·十年冷板凳(前247-237)** 5事件:献"灭诸侯成帝业"策、击赵疑间、郑国渠间谍案、**逐客令(锚点)**、韩非入秦之死(你救不救?)。
→ 伏笔:救韩非失败→法家同道离心 flag;谏逐客成功→六国遗士 ties 伏笔。

**S3 廷尉·并天下(前237-221)** 5事件:定郡县之议、议帝号、封禅之争、齐地三博士请封建、统一度量文书(治道大节点)。
→ 伏笔:郡县/封建路线直接写 `law` 与遗恨。

**S4 丞相·焚书坑儒(前221-212)** 5事件:**焚书之议(锚点)**、始皇求仙、坑术士460人、谏筑阿房/驰道(你谏不谏?)、扶苏谏迁北地。
→ 伏笔:扶苏线 ties 关键;焚书→名节、国祚暗线。

**S5 沙丘·一夜(前210)** 3事件:始皇病笃托孤、赵高夜访(**动态选项集,见3.5**)、事后清算或翻盘判定。

**S6 望夷宫·终局(前209-208)** 5事件:上疏劝二世外事、赵高构陷下狱、狱中自陈、廷尉狱、刑市(结局演出)。

## 5. 结局谱(双线正交矩阵)

|  | 秦二世而亡 | 秦延祚·扶苏立 | 秦崩·天下共击 |
|---|---|---|---|
| **具五刑族诛(史实线)** | 牵犬叹·默认 | 殉道·身后名 | 同狱俱碎 |
| **罢相归上蔡** | 苟全·犬可复逐 | 全身贤相 | 布衣观火 |
| **善终老寿** | 禄位终一身 | 元从第一功 | 明哲保身 |
| **封侯增邑** | 助纣之贵 | 安邦定国 | 乱世投机 |
| **沙丘举事** | 败·腰斩加速 | **中兴宰辅(真·改命)** | 诸侯并立之局 |

- 改命结局(`中兴宰辅`)需沙丘选 C 且翻盘判定过阈值 + 后续二世外事路线不回退。
- 目标可达率(熟练玩家):5%-12%;纯随机可达率 <2%。

## 6. 史书系统

沿用编年汇编,升级为**本传体**:阶段小标题(颍川李斯传/谏逐客/定法令/沙丘/具五刑),终局追加两段——
1. **太史公评语**(依状态模板生成:名节高→"阿顺苟合之讥"消失;附赵高→史实判词);
2. **千年后注**(一句话现代旁白,点破"这一局你改了什么/没改什么")。

## 7. UI / 美术方向

- 秦风水墨:玄黑底、朱砂点缀、小篆题字;状态条改 6 人生变量横条;底栏史书卷轴。
- 复用 urhox-libs/UI 体系,与蜀汉原型同一组件栈,无新增控件需求。

## 8. 技术架构(对现有原型的抽象改造)

```
scripts/
  FateEngine.lua      # 由 GameState 泛化:vars/反馈/年代时钟/动态选项集/终局矩阵
  Character/
    Lisi.lua          # 人物包:变量表/初始值/26事件/反馈实例/锚点/结局/文风
    Zhuge.lua         # 现有蜀汉数据迁移(验证抽象正确性)
  Chronicle.lua       # 通用化(本传体/编年体可配)
  main.lua            # 流程壳,不依赖具体人物
```
新增引擎能力:动态选项集回调(`optionsFor(state)`)、双线终局矩阵、年代锚点调度。

## 9. 数值验证协议(先于调平衡)

批量模拟(同五丈原方法,纯 Lua 跑 FateEngine):
1. 三策略对照:**贪禄保身**(选宠信/权欲增益大项)、**尽忠强谏**(选名节/治道大项)、**择友积援**(选 ties 大项+沙丘择机)。
2. 验收标准:三者终局分布必须显著分叉;`ties` 策略沙丘 C 选项点亮率 >60% 且翻盘率 <30%(有得选≠赢得了);"贪禄"策略具五刑率 >80%(史实再现)。
3. 若某结局占比 >85%,按蜀汉 star 问题的修法:检查是否存在单一硬衰减计时器,改为条件性消耗+对冲回路。

## 10. 范围与里程碑

| 里程碑 | 内容 | 不做 |
|---|---|---|
| M1 | FateEngine 泛化 + 26 事件数据 + 动态选项集 | 不碰美术 |
| M2 | 批量模拟调平(第9节验收) | 不做多人 |
| M3 | UI 秦风化 + 本传体史书 | 不做动画/音效 |
| M4 | 文案润色 + 结局矩阵演出 | 不加成就 |

明确不做:角色扮演式地图行军、多角色切换、联网对战(单机涌现足够承载主题)。

## 11. 风险与对策

- **风险**:沙丘选项集若"选C即翻盘",退化为分支树 → 对策:翻盘走阈值判定,且选后仍要过 S6 的"二世外事"路线拷问。
- **风险**:40 年跨度事件稀疏 → 对策:阶段内混入"日常治政"轻事件(小扰动),史书按阶段合并不逐回合刷。
- **风险**:玩家不读史,伏笔无感 → 对策:史书旁白在终局回点("建某年,你拒了赵高的第一封密信——今夜它又来了")。

## 五、测试与门禁(原报告 §五)

**恒真/弱断言加固(10 条全做)**:`audio.cjs`(在播要有 `paused===false && readyState>=2`)、`tapcloud.cjs`(频控检查点挪到 debounce 之后)、`chain.cjs`(settle 分支也记 residual;题签一致不接受 null)、`tapcloud.cjs`(覆写逐条比 `at`/`payload`;备份断言真内容)、`save.cjs`/`stash.cjs`(脏档统一用例)、`backtrack.cjs`(成就按探针名判定)、`settings.cjs`(音效/朗读补行为断言)、`voice.cjs`(串行预取改用真实并发数)、`save.cjs`(读档改走 UI 路径,断言 DOM)。

**测试台**:`load()` 等不到主菜单**抛错**并带上控制台错误(不再静默);异常取真描述(`exceptionDetails.exception.description`);`consoleErrors` 按 sessionId 过滤;CDP 端口交给 Chrome 自己选(`DevToolsActivePort`),profile 改 `mkdtemp` 唯一目录;每套额外写一份 UTF-8 报告到 `tests/.report/`;Chrome 改强杀(SIGKILL)+ 更长退避重试(Temp 里曾堆到 **213 个** profile,是批量跑时大批用例莫名失败的元凶)。

**运行器**:`run-all.cjs` 过滤空跑不再「0/0 套通过」并 exit 0(改为 exit 1);PURE 并入同一列表;`dev-check.cjs` 纳入;开跑前比对 dist 与 src 时间戳,dist 陈旧时醒目警告。

**新增三套用例**:

7. `prot` 侧 `test-jingke` / `test-chensheng` 各 2 项失败为**既有基线**,本轮未处理(与引擎改动无关,已用 HEAD 引擎复跑确认)。

## 0. 活动投稿（「涌现」创作活动，最高优先级）🔴

> 活动页：https://www.taptap.cn/poster/NIKiDS1YShdA
> ⏰ **作品须在 2026-10-21 中午 12:00 前上传并通过审核**，且官方建议 10-18 前上传——时间很紧，今天就该走流程。

**投稿步骤**：

1. 活动页面点「前往投稿」（或直接进入 TapTap 开发者中心 → 平台活动）。
2. 前提：游戏已上传并通过平台审核（Maker 项目走远端构建/发布流程；参赛通道为「创意工坊（H5 / TapTap 制造）」）。
3. 在 开发者中心 → 平台活动 中选择本活动、关联《青史志》、填写投稿问卷并提交。
4. 同时附上两份说明文档（本目录已备好）：
   - `AI素材使用说明.md` —— **必附**：游戏介绍里还必须写明「本游戏内含有使用 AI 生成的游戏资产」，否则视为放弃所有奖项评选；
   - `第三方素材说明.md` —— 霞鹜文楷字体（SIL OFL）声明。

**如何修改投稿问卷**：投稿后在 **开发者中心 → 平台活动** 可查看报名/投稿状态并修改内容（截止 10-21 12:00 前；审核被打回也是在这里改完重新提交）。活动页本身也可邀请队员、管理队伍。

**活动规则要点（与上架材料直接相关）**：

- ✅ 已自查**无联网功能**（multiplayer.enabled=false，未用云变量/排行榜）——活动明确禁止游戏带联网功能。
- ⚠️ AI 美术占比超 50% → 不能参评「最佳美术」，但不声明 AI 素材会失去**全部**奖项资格。
- 「全程参与奖」另需：开发期内在 TapTap 发布 ≥5 篇开发者日志（`docs/devlog/` 有 11 篇现成素材可整理发布）+ 试玩评审期有效试玩 ≥50 人。
- 审核可能驳回重传，务必留缓冲，不要压线。

## 1. 商店页面素材

| 材料 | 常见要求 | 状态 |
|---|---|---|
| 游戏图标 | 512×512 PNG（直角方图，勿自行裁圆角；不得白底/黑底/透明底） | ✅ `icon/icon-512.png`（另附 192×192 备用） |
| 商店截图 | 横屏 1920×1080，≥3 张，每张尺寸一致 | ✅ `screenshots/` 6 张（菜单/选本/事件/抉择/结算/个人史） |
| 商店文案 | 一句话简介、详细介绍、更新说明、标签、适龄 | ✅ `商店文案.md`（含待确认项） |
| 宣传主图 | 横版 ≥1920×1080，png/jpg，≤6MB；需带游戏名/LOGO | ✅ `promo/宣传主图-1920x1080.jpg`（415KB，PNG 原图同目录） |
| 横版封面（大） | 1920×1080，16:9，≤3MB；LOGO+标题，少文字 | ✅ `promo/横版封面-1920x1080.png/.jpg`（主菜单版式：花纹+竖排书法+朱印） |
| 横版封面（小） | 460×215，png/jpg，≤3MB；必须带 LOGO+游戏标题，不得有标题以外的宣传文字 | ✅ `promo/横版封面-460x215.png`（163KB） |
| 竖版封面 | 600×900，png/jpg，≤3MB；必须带 LOGO+游戏标题 | ✅ `promo/竖版封面-600x900.png`（738KB） |
| 竖版宣传图 | 与横版宣传图同内容，竖版裁切或定制（官方要求横竖各一张） | 🟡 可从宣传主图裁切 |
| 宣传视频 | 30s 内实机录屏，MP4；有视频时必须另传 1256×706 视频封面 | 🟡 需要时可做（录屏或生成） |

> 宣传物料规格来源：[TapTap 游戏物料要求](https://developer.taptap.cn/docs/store/release/publish/material/)、[TapTap PC 版物料](https://developer.taptap.cn/docs/pc-store/guide/pc-material/)、[制造封面教程](https://www.taptap.cn/moment/848096112626631532)。
> 三张封面按主菜单版式合成（`tools/compose-cover.py`），宣传主图为立绘版式（`tools/compose-promo.py`）；素材全部取自项目内（宣纸底 + 游戏内书法/印章 webp + 李斯立绘），无版权风险。

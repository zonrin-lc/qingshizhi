# 01 · 概述与设计支柱

## 1.1 概念(一句话)

> 重生历史人物,从第一道岔口起,你的每次选择都在对抗历史惯性:顺之者安,逆之者险。

多剧本历史偏移模拟器:以真实史实为基线,在每个历史分歧点,玩家的选择只扰动时代的状态量,系统按规则自动推演一条没人写过的路;终局以仿《史记》体史传收束。首发五剧本:李斯、荆轲、韩信、项羽、陈胜。

「涌现」在本作中的定义:结果来自规则之间的相互作用,而不是来自预设剧本。判定一个机制是否涌现,看它有没有对应的"预设分支表"——本作的设计目标是**任何分支表都不许存在**。

## 1.2 三个卖点

| # | 卖点 | 机制承担 |
|---|---|---|
| 1 | **与历史对弈,而非观看历史**——史实是对手盘:给参照,也给反噬。玩家永远知道原本的他会怎么选,所以选择有重量 | 「史」字标记 + 偏离度段位 + 历史修正 + 选项集被状态裁剪 |
| 2 | **每个决定立即有回响**——点击选项即弹出结算文本与数值变动,零延迟反馈,形成选—看—再选的心流 | 交互铁律(02 章):结算必须先于叙事推进,0.5 秒内可感知 |
| 3 | **结局即一篇史书**——每个结局配一段仿《史记》体史传总结,整局通关凝结为一段可分享的个人史 | 结局页:本局个人史 + 印章 + 四维评分 + 雷达图 + 分享卡 |

## 1.3 目标用户分层

| 层 | 画像 | 主钩子 | 体验档 |
|---|---|---|---|
| 核心层 | 历史爱好者、文字游戏玩家、策略轻度玩家,18–35 | 卖点 1(对弈的重量感) | 普通 60–90 分 |
| 泛用户 | 被"如果你能改写 XX 的命运"吸引,碎片化 | 卖点 2(即时回响)+ 卖点 3(史书分享) | 剧情 40–60 分 |
| 硬核层 | 挑战型,追求逆天结局与高评级 | 卖点 1 的极限形态:逆天段位的反噬博弈 | 硬核 90 分+ |

三层共用同一套系统,差别只在进入深度。

## 1.4 体验基准

| 维度 | 基准 |
|---|---|
| 单局时长 | 剧情 40–60 分 / 普通 60–90 分 / 硬核 90 分以上(含回溯试错) |
| 一局决策点 | **事件抉择页 15–22 个**(实测口径;旧锚 25–35 作废,见附录 B) |
| 重玩动力 | 单剧本 ≥8 种结局(实测 12–20)、≥3 条通关路线(苟活/稳健/逆天) |
| 载体 | 零依赖 HTML5+JS,手机浏览器直开,支持 PC |

时长自洽验算:单决策点 1.8–4.0 分钟 × 15–22 = 40–60 分,与基准吻合——决策点必须是"真正需要想的岔路口"的计数,不得掺入操作次数。

## 1.5 四条设计支柱

### 支柱 1:选择有重量

**含义**:每个选项必须同时做到两件事——改变当下数值,**并且**改写历史走向(推高偏离度、种下伏笔、或改变世界后续)。判定"装饰性"的标准:**把该选项删掉重跑模拟,结局分布若无差异,它就是装饰,不配占决策点。**
**落地**:数据层——每个选项至少改变一个状态量(C1a,拒载级);界面层——结算弹层必须展示"变动的数值+本局个人史新增的那一条";验证层——历史侧配比观察(C1b,见 05 章)。
**反例**:茶肆闲谈给个"听听说书(无变化)"选项——占预算、稀释心流,教会玩家跳过结算弹层,卖点 2 的心流当场断链。

### 支柱 2:历史有惯性

**含义**:惯性不是旁白,是数值——偏离度 0–100、全局唯一、只增不减、四段位,玩家能看见、能计算、能博弈。偏离度越高,世界对玩家的修正反噬越强;顺原有历史进程相对安稳,逆天选择凶险——**逆天是博弈,不是福利**。(反噬的具体机制见 03 章,支柱层只立原则。)
**落地**:顶部常驻偏离度指示条与段位名;选项集被状态裁剪——玩家当下握有哪些选择,由一生状态与偏离段位决定。
**反例**:偏离只涨不咬、逆天零成本——退化为无代价改写历史的爽游;同时"选择有重量"一并塌掉:逆天既然无痛,循史失去全部意义。
**已结案**:高段位有配套回报——逆天专属结局池(资格)+ 总分×1.15(结算);它奖励的不是"变高",是"待住":每章照付两份修正。

### 支柱 3:人物有温度

**含义**:数值是骨架,体验是血肉。所有结算文本第二人称、带该人物的具体意象;语声区分人物——五个剧本不共用一套句式(提案:写作规范章执行)。定量标准(提案):删去全部专有意象后仍然成立的句子,即不合格的报告句。
**落地**:结算弹层;结局史传与本局个人史的行文;事件正文的史实引文。
**反例**:"宠信+5,党援-3,胡亥即位。"——像 changelog;玩家意识到自己在一台 Excel 里附身名人,"改写命运"的钩子变空头支票。人不会对数字心疼。

### 支柱 4:失败有尊严

**含义**:失败结局不是 game over,是一篇完整的仿《史记》体史传——死本身就是内容、是可收集物。复盘机制把败局转化为下一局的信息;回溯不清成就与图鉴(06 章硬规则)。元规则:8+ 结局中,失败态与成功态同等写作质量。
**落地**:结局页=史传总结+印章+四维+雷达图(可分享的个人史);复盘=结局页界面;收集=百科词条图鉴+成就。
**反例**:失败→黑屏一行模板字"伏诛,族灭"弹主菜单——投入八十分钟换一份电报;失败不可读,则无攻略价值、无收集欲、重玩断供,而重玩是涌现玩法的生命线。

## 1.6 四支柱与涌现

支柱 1+2 构成自反馈闭环:选择写进偏离度(1→2),偏离度决定反噬强度与选项集裁剪(2 咬回),裁剪改变"下一步什么是聪明着"(2→1)——收益矩阵是移动靶,没有背板可背。这就是"结果来自规则相互作用"的机制学保证:史书的参照是设计师写的,本局个人史必须是系统写的。
支柱 3 让涌现可读(变量账本翻译成人话);支柱 4 让涌现值得采样(把"输一局"改写成"收获一篇新传记")。
**一句话:支柱 1 把选择写进系统,支柱 2 让系统咬回来,支柱 3 把咬痕翻译成人话,支柱 4 让玩家愿意挨下一口。**

```

   ↓ 按章推进(序章至终章;一章=一幕人生)
   ┌──────────────────────────────────────────┐
   │ 章首:历史情境旁白(一小节一页,整节渲染,逐句渐显) │
   │   ↓                                        │
   │ 回合循环:每回合发 4 张卡                       │
   │   · 关键事件卡 ×1(顶栏常驻,倒计时初值 3)         │
   │   · 普通行动卡 ×3(本章行动池随机抽,同轮不重复)    │
   │   ├ 打出行动卡 → 倒计时 −1 → 未归零:下一回合       │
   │   └ 倒计时归零 → 自动开抉择页(待决,必亲自选)       │
   │   ↓ 本章关键事件全部关闭                        │
   │ 章末结算:属性面板 + 章末偏离度变化 + 历史修正判定   │
   └──────────────────────────────────────────┘
   ↓ 终章 → 结局判定 → 结局页(史传总结=可分享的本局个人史)→ 复盘/回溯再开
```

**每层设计意图**
- **入口漏斗**:四步各收窄一件事——时代氛围/具体命运/体验档位。朝代分组使剧本库可扩展而导航不塌。
- **章(时间容器)**:章首旁白在每次抉择前先把"原本历史往哪走"摆明——对手先亮棋谱,再轮到你落子。章末结算三项并置,是"与历史对弈"的周期战报。
- **回合发牌**:每回合 4 张卡把推进切成均匀心跳;行动卡随机抽、同轮不重复——抽到什么由不得你,怎么处理由不得历史。

**关键事件卡倒计时解决的三个问题(核心)**
1. **"拖"第一次成为有代价的维度**。没有倒计时,抉择只有"选哪个";有了它,"何时面对"也成了选择:早打行动卡→有更多行动塑造临场;晚打→史实继续压近、留给你的窗口收窄。偏离度管"偏了多远",倒计时管"以什么姿态撞上节点"——惯性的两副面孔,一副是数值,一副是节奏。
2. **给"必须亲自选"一个不妥协的执行机制**。归零强制开页,不能挂机、不能跳过——15–22 个决策点因此全部保证是"你选的"。
3. **它是章进度的唯一节拍器**。关键事件全部关闭=章末,不用额外进度条,历史本身就是关卡。
4. **最深一层(不预告带来的)**:见 2.3——准备失去信息支撑,行动卡从"刷属性"变成"押注"。

**玩家行为决定 vs 按剧本推进**
- 固定节拍:章结构与旁白史实内容/关键卡入场时机与时限/"史"字标记/行动池成员/裁剪阈值——剧本定题。
- 自由落子:出牌节奏(每轮打几张先打哪张→倒计时快慢)/抽卡取舍/抉择页选项(顺史或偏航,直接决定偏离跃升与变量扰动)/被裁剪后的可见选项面/章末偏离读数。
- 结构合式:剧本定"何时出题、有哪些题";玩家定"怎么答、以什么状态答"。固定的是考试日程,自由的是备考路径与答卷。

## 2.2 关键事件卡三状态(待启/开启中/待决)

| 状态 | 进入条件 | 界面 | 玩家可做 |
|---|---|---|---|
| 待启 | 事件挂入,倒计时>0 | 顶栏常驻卡背+「再打出 N 张行动卡后开启」;**不显示事件内容与可选方向** | 打牌或蓄势;倒计时随打出行动卡 −1 |
| 开启中 | 倒计时=0 | 卡背翻面过渡(极短) | 若有待插入事件先执行,否则即进待决 |
| 待决 | 抉择页开启 | 全屏抉择页;"史"字标记;选项集被状态裁剪;不可跳过 | 必须选定一项→结算:变量扰动+偏离度增量(可为 0) |

流转:待启→开启中→待决→结算→下一事件回待启(倒计时回满 3)。**同一时刻全场仅一张关键卡,不并行,不留扩展口。**

## 2.3 单回合格式规格

**常量**

| 项 | 值 |
|---|---|
| 关键卡倒计时初值 | 3(单位=打出行动卡数,非回合数) |
| 每回合发卡 | 关键卡×1 + 行动卡×3;打完手牌即入下回合(无"只打一张就过回合") |
| 章行动池 | 恰 12 张:通用行动(全章)+章节限定行动(仅指定章) |
| 抽卡 | 每回合从池抽 3,同轮不重复(跨回合可重复抽中→触发递减) |
| 收益递减 | 第 n 次收益=⌊v/2^(n-1)⌋,下限 ±1;代价不减;同章内计数,每章重置 |
| 章进度 | 顶栏「已通过关键事件 x / n」,n 随条件起点自动校正;仅抉择结算计入 |
| A1 | 关键卡不入手牌,以顶栏常驻指示呈现 |
| A2 | 回合结束未打出的手牌弃置,下回合重新抽发 |

**行动卡状态机(抽到→结算)**

```
抽到(入手)
 ├ 可打出 → 点选 → 结算 → 弃置
 │    结算(卡面固定定义,玩家不指定对象):
 │    ① 变量扰动(收益按递减,代价原额) ② 可能种伏笔
 │    ③ 在场关键卡倒计时 −1(唯一正常递减路径)
 │    ④ 检查待插入事件 → 有则先执行插入,归来按类型处理倒计时
 └ 条件不满足(资源门槛等) → 锁定态:灰置+明示原因;不计入处理进度、不递减
回合结束:未打出者弃置(A2),下回合重抽。
```

**防死锁(唯一兜底)**:行动卡全锁定→**不触发任何兜底**,弃牌重抽、倒计时不变(打不出牌=时间变多,设计自纠正;重置会白送时间并可能在牌少时自旋)。**唯一兜底**:待决页全部选项锁死→关闭抉择页、事件退回待启、倒计时重置 3。这是全规格唯一兜底。

**收益递减推导与示例**(v=+10,代价恒 −5):

| 第 n 次 | 收益 | 代价 | 边际净 | 累计净 |
|---|---|---|---|---|
| 1 | 10 | −5 | +5 | +5 |
| 2 | 5 | −5 | 0 | +5 |
| 3 | 2 | −5 | −3 | +2 |
| 4 | 1 | −5 | −4 | −2 |
| 5 | 1 | −5 | −4 | −6 |

最优停手在第 1–2 次之间,而"停在哪"取决于当下多需要那 +10——节点不预告,这个"需要"无法预先精确知道。
**为何代价必须不减**:若代价同步递减,净收益 ≈(v−c)/2^(n−1) 在 v>c 时恒正→存在全章通用、全剧本通用的最优刷牌循环→行动卡退化为白嫖机器。代价不减后边际必在有限次内转负,12 张卡无一能无脑刷到上限。逆向属性同理:危机是逆向属性,"降危"作为收益照样递减,单卡降危总量被几何级数封顶,反复刷行动刷不下危机。

**插入事件两类**
- 甲类·旁支插入(随机际遇):挂入,处理完回原事件,**倒计时回满 3**;际遇不消耗决策点。
- 乙类·接管关键卡(构陷/暗杀/清算、死亡判定、反噬):接管卡位、原事件暂存、处理完归还,**不额外回满**,按剩余倒计时继续。构陷用乙类,因为它就是冲你的状态来的。
- 不打断待决:乙类到达时若关键卡已在待决,挂起至该次抉择结算后再接管,挂起上限 1(新的接管事件覆盖挂起者,不排队)。理由:抉择页是唯一需完整阅读的界面,"构陷是历史的无理,但它至少等你说完这句话"。

## 2.4 蓄势(策略牌,回合级操作)

| 项 | 规定 |
|---|---|
| 定义 | 打出蓄势=放弃本回合出牌(视为回合结束,当前手牌弃置适用 A2),不递减倒计时 |
| 状态 | 二值未蓄/已蓄,不累积(已蓄期间再按无额外效果) |
| 代价 | 放弃本回合三张行动卡的变量扰动 + 放弃三次倒计时递减(事件推迟) |
| 兑现 | 下一次事件抉择的险招成功率 +10 |
| 清空 | 该次抉择一旦做出即清,无论是否选险招、成败 |
| 含 | 关键事件抉择、随机际遇内的抉择 |
| 不含 | **行动卡上的险招——蓄势不加成**(实测确认)。蓄势只买"抉择"的确定性,不买"行动"的确定性 |
| 决策点 | 蓄势不计入(仅抉择页计入) |

**形态裁定**:采用"回合级固定操作"(非抽牌式特殊牌)——取舍必须每回合真实发生(这三张扰动+三次推进换一次 +10,值不值?),抽牌式会让一部分回合根本没有这个二选一。
**跨章规则**:章末结算不含抉择,故章末蓄势跨章保留、兑现于下一章第一次抉择;策略含义——章末蓄势是在赌"下一章开局就有险招",因不预告而无法预先计算,**全作最纯粹的一次押注**。
**调参纪律**:若实测蓄势使用率过低,优先调内容侧(险招档位与密度)与难度系数,**不动 +10**。

## 2.5 险招(抉择页与行动卡通用)

**门槛判定**

| 类型 | 适用 | 未达标 | 界面 |
|---|---|---|---|
| 软门槛 | **能力量与状态量——十一维任一(含身外)** | 不锁定,进险招掷骰 | 可点,显示成功率(非硬核:最终数值;硬核:档位词) |
| 硬门槛 | 处境与事实固定词表(伏笔·有/无/任一、处境·章数、偏离·上下限、危机/权势/君心·上限、君心·峰值下限) | 命中即锁 | 灰置+明示锁定原因 |
| 支付能力检查 | **仅行动卡语境的财富键** | 付不起直接锁 | 同硬门槛 |

**行动卡可设险招**:行动卡门槛含软门槛(谋略/文才/辩才/武力等出现过),走同一套掷骰+烧毁。真实差别收窄为一条——财富在行动卡语境=支付能力硬检查,在事件选项=普通软门槛。设计陈述:**同一玩家,这一手赌在行动卡上还是抉择页上,决定了他能不能用蓄势买下这份确定性**——攒牌面/赌命的二分,不只是难度差异,还是可支配资源的差异。
支付能力为何锁:①支付是事务性条件,无"差一点"连续量;②若允许"掷骰付款",失败后钱扣不扣、动作生不生效产生未定义中间态;③行动卡打出即生效是节奏地基,不能被付款随机性击穿。
**A3 达标语义**:全部软门槛满足=不掷骰、点击即成——"险"的定义就是不达标硬上;界面上没有成功率,本身就是"这条我能不能靠本事办"的信号。

**成功率合成**
`最终率 = 史升档( 阶梯( 各未达标软门槛的最大差值 gap ) ) + 蓄势`
六档:gap≤3→70/≤6→50/≤9→40/≤12→30/≤15→20/>15→15。史升档(带「史」):≥50→70/≥40→50/≥30→40/≥20→30/余→20,封顶 70。蓄势 +10 不封顶。**单次险招全局上限 80%**(史升档到 70+蓄势 10)。多软门槛不达标→**取最低档不叠加**。示例:差值{2,5,10}→10→30%,带史→40%,已蓄势→50%。
**设计理由入正文**:史升档封顶 70 是刻意的——顺历史也不该稳赢,历史惯性给的是概率不是承诺;蓄势 +10 允许把这个承诺买到 80%,代价是一整个回合,再高就压不住。

**掷骰(五条独立随机流)**
骰子流(险招)/事件流(章内事件调度)/抽卡流(行动卡抽取)/际遇流(际遇触发与抽取)/修正流(修正条目抽取)。任一流推进不改其余四流序列——否则重试时"骰子换了牌也换了",那不叫重试,叫换了一套游戏。抽取值≤最终率即成功。失败→该选项**烧毁**。

**烧毁**:触发=险招失败;对象=该选项(烧的是"这个做法"不是"这条路",同一目的可经其他选项/章节达成);**定位键为三元组(章号,事件号,选项序号)**——作用域是同一个事件**这一次**不能再选,**回溯会清空它**(退回章首,这道疤一并抹去;属性涨上去、事件重进,选项即回来),「史」标记不豁免;呈现=保留可见+置划线+不可点+**显示烧毁原因**(玩家需要知道"这条路我试过"才能真正绕开,隐藏会让他反复撞墙而不知所以)。**定性**:烧毁防的不是重复刷,是**同一次抉择里反复掷骰直到成功**——玩家看到选项时已掷过一次,划线只锁"在这个事件里换条路径回来重试同一颗骰子"。失败被记住的方式不是永远失去它,是**这一次不行**;与支柱 4"失败有尊严"相容:尊严来自可读的归因,不来自永久的没收。

## 2.6 交互铁律

> **【结算必须先于叙事推进】** 玩家点击后 0.5 秒内必须看到结果反馈。不允许"选项后接大段叙事、数值藏在角落"。

**为什么是设计约束不是 UI 需求**:游戏全部主张(与历史对弈、选择有重量、命运由扰动推演)成立在一个前提上——**玩家对世界状态的内心模型与引擎真实状态基本同步**。抽掉它:卖点 2 不存在;支柱 1 无法被感知(有重量的选项和装饰选项在玩家眼中无法区分);支柱 2 名号破产(看不见就谈不上计算);本作坍缩回它宣称反对的东西——互动小说。UI 需求改错不好看,这条改错**游戏没了**。

**强制清单(逐条验收)**
- [ ] R1 点击→结算文本+数值变动先于任何后续叙事(0.5s 内可感知)
- [ ] R2 叙事逐句渐显,不整段倾泻
- [ ] R3 数值变动弹幕式提示,不用弹窗;且不阻塞继续操作
- [ ] R4 一小节一页、整节渲染,不做无限滚动
- [ ] R5 属性面板随时可开,变动条目高亮
- [ ] R6 配音用 Web Speech API,可开关
- [ ] R7 移动端竖屏优先,单手完成全部操作
- [ ] R8 关键卡不可主动点开(开启之前不许偷看)
- [ ] R9 抉择页必须完整呈现:全文逐句渐显读完,不折叠不跳读,未读完不得出现选项;读完必须选定一项,无返回无跳过;呈现与选择之间不插入其他界面(开启之后必须看完)
- [ ] R10 行动卡结算同样适用 R1(打出瞬间扰动与倒计时变化可感知)
- [ ] R12 烧毁选项:划线可见+不可点+显示原因
- [ ] R13 硬门槛锁定选项:灰置+明示原因
- [ ] R14 顶栏常驻:偏离度条与段位、关键卡倒计时、章进度 x/n

R8/R9 是一对:两头堵死,中间才是完整的抉择。0.5 秒是因果绑定的时间窗口,不是性能指标——它守住一条因果链不被叙事重新包装成命运:结算先行强迫世界先开口,先让你看见它变了,再听它说什么。这正是"与历史对弈"和"观看历史"的全部技术差异:对手落子的声音,必须响在你出手之后、下一手之前。

## 2.7 反例检验:去掉行动卡,只剩事件抉择会怎样

1. **"何时面对"整个消失**——只剩"选哪个",玩家从博弈者退化为批卷人。
2. **决策点密度崩盘**——15–22 个节点到期串成无缓冲长队,40–60 分钟里全是抉择页,旁白与章末战报失去穿插空间,心流变疲劳。
3. **裁剪退化为静态查表**——门槛跨越只能靠节点选项一次跳变,"被状态裁剪"从渐进养成变成过场。
4. **三路线不可玩**——路线差异靠一路攒状态;没有行动卡,"攒"没有动作可指。
**一句话:行动卡承担的不是内容量,是内容的时间形状——把剧本从"一串题"变成"一段有呼吸的岁月"。**

# 03 · 数值系统

## 3.1 十一维属性

| 属性 | 组 | 语义 | 角色 |
|---|---|---|---|
| 体魄 | 自身·天赋 | 健康、耐力、伤病恢复 | 软门槛(开门) |
| 武力 | 自身·天赋 | 剑术、阵战、搏杀 | 软门槛 |
| 文才 | 自身·天赋 | 文学素养、著书 | 软门槛 |
| 谋略 | 自身·天赋 | 庙算、布局、识势 | 软门槛 |
| 辩才 | 自身·天赋 | 口舌、游说、纵横 | 软门槛 |
| 财富 | 身外·经营 | 资财 | 事件里软门槛;行动卡=支付能力(硬);结算与判定 |
| 名声 | 身外·经营 | 士人、舆论、当世评价 | 同上(软门槛为主+结果) |
| 权势 | 身外·经营 | 官职、实权、对官僚系统的控制 | 软门槛;功业公式主项(峰值);权势·上限硬门槛 |
| 政绩 | 身外·经营 | 行政与军功建树 | 可作门槛与结算内容;**不进功业计分** |
| 君心 | 身外·经营 | 当权者对你的信任 | 软门槛;君心·上限/峰值下限硬门槛 |
| 危机 | 身外·经营 | 环境敌意累积,逆向属性(越高越坏) | 危机·上限硬门槛;构陷/死亡线触发源 |

隐藏值:偏离度(专属顶栏,不入面板)+ 各剧本自有主敌隐藏值。

**分工规则(精确版)**:十一维分两组是**倾向**,不是规则——写剧本时优先用自身五维当钥匙(与"这个人会不会做这件事"语义匹配),但身外维度同样开得了门且常常必须开(有些路要名望才走得通,有些决定要君心够高才敢下)。真正的规则在门槛形态:**能力量与状态量→软门槛可赌;处境与事实→硬门槛锁定**(见 02 章门槛表)。分组管"设计时往哪找钥匙",不管"哪一维能当钥匙"。

**为何拆两组(混装的三条危害)**:① 旧"才学"一筐装三种天赋→所有才学路线挤同一个门槛,角色专精(如"请以辩代刀"开在辩才不开在文才)在数据上不可表达;② 武力/体魄无处安放→初始人格说谎;③ 能主动攒的与只能被动得的混在一根轴→玩家因果直觉无法建立。拆后"自身可主动攒、身外由世界折返"分轨,三线分流(诗名/游侠/干谒类通道)成为可能的剧本语法。

**初始值原则(开局即人格)**:P1 主线顶格短板见底,数值场一眼可读;P2 每人至少一扇当场能开的门(全维非零起步);P3 低值即出身;P4 双门贴近=文吏路径;P5 高而未满=留出屈辱与成长的刻度(顶格留给兑现之后,开局顶格的人物没有故事可讲)。实测锚:五人初始见 05 章剧本表。

**呈现**:面板两栏「自身|天赋」「身外|经营」;全维 0–100,危机标逆向;变动量总则±2~±15(超例逐条豁免登记,无暗账);硬核走档位词(可逆推 W3,词从人物嘴里出 W1,逐维度立表 W2,危机反向出词 W4)。
**与"选择有重量"**:属性不是用来读的是用来踩的——重量开在门的开关上(选项面标门钥:亮/可赌/锁定+原因),面板是验尸房不是驾驶舱;两栏即心智;变动高亮收窄注意力;档位词即极端降维。维度变多没有稀释重量,只稀释了"读面板"的必要性——本作的面板本来就不是用来读的。

## 3.2 偏离度与历史修正

**它到底在量什么**(三层):表面——你离史实多远;第一层——**历史对玩家预测的失效程度**:每个关键事件都是编写者押的注("这时他会这么做"),偏离度累计被破掉的注;第二层——四段位不是线性尺是**模式切换的临界线**(修正池按区间组织、结局资格按区间声明、硬门槛直接检视偏离上下限),0–100 不是"偏了 0%~100%",是"世界用四种脸看你";第三层——**全作唯一的时间之箭**:属性可攒、际遇可躲、烧毁回溯即清(仅锁这一次),唯它不可逆——全作真正不可逆的只有偏离度这一条线。镜像:偏离度量"世界猜不透你了",险招的骰量"你猜不透世界了"——双方互盲才叫对局。
**严格定义**:输入源只有两个——抉择结算的增量(剧本逐选项声明,**0 是常态**)+ 章末偏离度变化(剧本声明,可为 0)。负增量引擎直接丢弃。行动卡默认不改偏离度(结构上禁)。

**四段位表(含真空区与三节奏)**

| 段 | 值域 | 章末修正 | 章中反噬 | 设计意图 | 玩家实际经历 |
|---|---|---|---|---|---|
| 循史 | 0–20 | **完全不进入判定(真空区)** | — | 先学会读史再学改史 | 世界按熟悉的剧本运转,"史"字是可靠地图;压力是自己给的:每章想留在这里就要持续选零增量项 |
| 微澜 | 21–45 | 概率触发(时有时无) | — | 给第一次试偏定价 | 尝到史实外之物,第一次章末挨修正——历史第一次主动对你说话;课程:**选择的价不在选择时付,在章末付** |
| 改流 | 46–70 | **无条件,每章必发** | — | 脚本失控,进入清算期 | 熟悉情节不再如期出现;上一段的后悔全部变成沉没成本 |
| 逆天 | 71–100 | 照发 | **每章另加一次** | 终局冲刺区 | 旧脚本基本失效,面对规则相互作用生成的新史;每章付两份;问题只剩一个:撑到结算页 |

三段三节奏(微澜间歇/改流准点/逆天翻倍)是段位识别的免费通道:玩家从挨打节奏就知道自己进了哪段,不需要看数值。

**历史修正规格**:章末三步(属性面板→偏离度变化→修正判定)。修正池=剧本数据,**恰 9 条、正向 0 条**(验收计数)。每条字段 {生效偏离度区间(任意,可细化于段位), 触发概率, 标题, 文本, 负向属性变动}。**两步判定**:①修正流取一数,当前区间池内任一概率过线即触发(微澜执行此步,改流及以上跳过=无条件);②区间内**均匀抽一条**。条目概率只管"来不来"不管"来哪条"。**成分**:一段遭遇文本+一组不利方向属性变动(实测样本:减名声/减君心/增危机/减权势)——文本是它怎么发生,变动是它留下什么;只给文本是故事,只给数值是税。**修正无正向**:玩家不需判断福祸,只判断扛不扛得住;任何"补偿"都会让玩家把挨罚算成投资。**修正不附带伏笔**:伏笔是玩家选择的产物,修正不是;若罚能种伏笔,玩家会开始期待被罚——反噬变成另一种奖励,偏离度的压力结构当场失效。**修正只施加后果,不提供后续,它永远是纯粹的损失。**

**六个修正情境**(抽象,通用于任何剧本):微澜负例——老同僚会盟时与他保持距离,一份顺利流转的文书被无端"留中":历史不惩罚他,历史只是**不再配合他**;改流负例——上位者手里出现一份针对他的质问:君心没掉数字,**猜疑本身作为遭遇降临**;逆天负例——身边人被安插、庇护变监视网:历史不再纠正他,历史开始**设防**(三档负例的升级线:不配合→猜疑→设防)。

**只增不减:代价,不是缺陷**(三条理由):①可减的偏离度自我取消——偏离度量化的是轨迹破掉多少因果,可回滚即"你现在离哪个状态近"的无定义物;能回滚的"偏"叫和历史做买卖;②代价有上限且被三条规则封顶——回不去但**停得住**(零增量永远存在;若剧本章末变化声明 0 则严格成立)、后悔由 meta 层(复盘+每局重置)承接、资格换算是终局时点判定;③不可逆是主题需要的唯一一条线——烧毁降级为一次性锁定后,全作仅剩此线不可回滚;若连它都可回滚,"选择有重量"的最终裁判(无法撤销)就不存在了。

**闭环**(两条回路边,性质不同):
- **资格回路(机械闭合)**:偏离↑→安全向结局资格被逐出、改命向资格进入→可达终点集合缩小位移→章级策略被迫翻转:低段保资格,高段朝只剩的出口打。不经玩家大脑,引擎单方面执行的沉没成本。
- **压力回路(认知闭合)**:负向修正文本→玩家感到代价→下一段零增量选择的意愿被定价。引擎只喂偏离度两个口(抉择、章末变化),修正本身不增偏离度——数值上环不自激放大;它转得起来是因为**玩家把叙事读成了价格**。机器里只有前馈,回路合在人的判断里——这正是涌现与脚本的分界。

## 3.3 节点异变与逆天反噬

**节点异变规格**:历史上记载为关键转折的年份=剧本的节点。节点是固定的物(年号/人物/事态,史实);异变=同一节点、玩家走进去看到的局面不一定是史书那一版,**由此前累积的状态裁剪出来**。
数据分层:固定层(节点名表:标识/名/史实原貌一句话;"史"字选项)编写期定死;裁剪层=该节点全部候选选项带门槛,可见选项集=f(当前状态,节点定义);呈现=节点名标"这里**本来**发生过什么",裁剪局面标"**现在**是什么样",两行并排互文即异变。
**保证"裁剪非随机"四约束**:① f 是确定性纯函数,体内禁一切随机源(不碰五条流);② 随机只存在于调度(事件流/抽卡流/际遇流管"哪个回合遇到什么"),不存在于内容;③ 可重放验证:同操作序列重放,每节点选项集逐字节相同;不同序列的差异必须逐项指回状态变化;④ 编写审查:存在"状态全同局面不同"的可能=bug 退回。

**逆天反噬规格**:偏离≥71 后**每章必遇一次,确定性规则**;"随机"只指从逆天段重度条目中抽哪一条,不指会不会来。形式=**乙类·接管关键卡**(与构陷同机制:暂存原事件、换上自己、处理完归还、不回满倒计时)。形态:标题与正文=被抽中的那条重度修正;**选项只有一个「咬牙撑住」**,无险招无门槛无第二选择,点下直接结算该条负向变动。抽取走**事件流**(非修正流)。
**实现教训(存档)**:此机制曾被实现成概率触发,后修正为确定性——概率版本下玩家无法回答"硬扛这一章值不值",没有价格的东西不能买卖,玩家只能赌,赌没有策略也没有对局。确定性把价格钉死,"还能扛几章"成为算术题。**可预期的代价叫价格,不可预期的才叫惩罚。**
**它是仪式不是抉择**:把惩罚从"你必须做一个艰难的决定"降级为"你必须接受一件已经决定的事"。逆天段给的不是选择权,是清醒;能动性全部前移到"如何让自己扛得住"(危机经营、资源储备)。乙类不回满倒计时,连"借反噬白赚时间"的形式漏洞也一并堵死。
**三层压力分工**(两阀独立):构陷(危机 70–89,乙类,每章一次,可双向调节)/反噬(偏离≥71,乙类,每章一次,单向棘轮)/死亡线(危机≥90 章首判定、≥100 致死难度即死)。**前两者每章各来一次、互不干涉**:玩家可压危机<70 躲构陷同时留逆天吃反噬,也可放任危机冲 89 再花一章降回来。危机阀管"世界派多少人算计你"(可拧),偏离阀管"世界还剩多少剧本认识你"(不可逆)。这是本章给玩家最有分量的操作空间。
**"反噬不是随机惩罚"判据(内容审查标准)**:事后玩家应能说出"这是因为我第几章做了什么"。说不出,该条修正退回重写。支撑:① 触发源只有偏离度,而偏离度只由抉择推动(机制上无反噬的随机入口);② 内容书写追溯式(文本指向玩家改掉的那件事);③ 损失不伪装奖励(无正向、不种伏笔);④ 账本全程可见(0.5 秒结算、烧毁疤、逐条修正)。对照真随机惩罚:无因、等概、不可归责、下次可翻盘——反噬四条全不占。**它不是老天爷,它是账单。**
**例(抽象)**:某玩家第 3 章末偏离 71→第 4 章 85→第 5 章停在 85。第 4 章:章中反噬接管(清算型:旧痕被翻出、君心−8 危机+6),同时他把危机经营在 60(构陷阀全关)、压着倒计时晚撞节点——入逆天从抽象段位变成账户余额;第 5 章:再吃一次(孤立型:名声−6 权势−5),同时全程零增量把 85 钉死。**他想收手回循史:回不去**——85 永远≥85,循史/微澜/改流的资格全部永久出局;能做的只有两件事:停止推高,以及拧危机阀(降回 70 以下躲构陷)。**他能收的不是历史,是历史对他的下一份耐心。**

**节点异变如何让涌现可玩**:涌现的难点不在生成在交互。裁剪给了三个推论:① 状态即选票且可提前写——每张行动卡、每次经营、每枚伏笔都是对未来节点"我见哪一版"的预先投票,选择有重量获得跨时间表达;② 可学所以可策略——随机变异不可归因不可规划,状态裁剪的变异是可读反馈系统,第二局会归纳、再用归纳指导下一手,"与历史对弈"要有弈字,弈的前提是棋路可学;③ 组合爆炸替设计师写了不存在的内容——作者只声明候选项与门槛,局面从玩家×节点的乘积现场生成,**内容表是有限条目,局面是笛卡尔积**。收尾:节点名标"本来发生过什么"、裁剪局面标"现在是什么样"、修正给回礼——三栏对照里,异变不是反对历史,是玩家与历史相互作用留下的可读取笔迹。

## 3.4 三难度

**主论点**:硬核的难度不来自更严的数值,而来自**更少的信息**;它不是"普通×倍率",是同一游戏在信息维度的另一档。对已理解系统的玩家,硬核的每一分钟是一次信息剥夺;对未理解的玩家,硬核只是一片噪声。考的不是手熟,是理解。

**全局锁定五列**(剧本仅引用不得覆盖;危机系数若可改,硬核的"危机更重"就不再是硬核的定义,而成为剧本作者的偏好):

| | 危机系数 | 修正危机系数 | 总分系数 | 回溯 | 致死 | 属性隐藏 |
|---|---|---|---|---|---|---|
| 剧情 | 0.6 | 0.5 | 0.8 | 无限 | 否 | 否(全数值) |
| 普通 | 1.0 | 1.0 | 1.0 | 每章一次 | 是 | 否 |
| 硬核 | 1.2 | 1.3 | 1.25 | **无** | 是 | **是(档位词)** |

系数作用域(两条并行通路,不串联):危机系数=一切危机正增量(抉择给的/章末持续结算给的/属性触阈值的隐性触发);修正危机系数=**仅**历史修正条目的危机增量。硬核实际效果:抉择危机×1.2、修正危机×1.3,同一份危机不被乘两遍。
险招六档与史升档**全局单值不随难度**(难度应改变你承受的总量,不改变你下注的赔率;赔率若浮动,难度就不是同一游戏的另一档信息量)。
**硬核无存档**:导出直接返回空、不写入——不是"存了读不了",是根本不存。剧情/普通有存档。
**必须写透的反直觉:硬核是分数最高的难度**。合成值 70 在硬核即够 S(×1.25=87.5,叠逆天×1.15=100.6);普通需 85;剧情即使四维打满 100、不走逆天只有 80=A,回溯 20 次掉到 53=C(勘误存档:曾误记为 D,按曲线 35 次回跳才入 D)。这不是漏洞:**评级不是难度指标,是同一次游玩在不同处境下的读数**;硬核系数是对其四重代价(危机更重、修正更狠、不能回溯、信息全盲)的补偿。玩家在这种条件下打出好局,理应拿到更高评价。
剧本隐藏值的直觉句呈现**各难度一致**(不是硬核专属)。

**为什么"无存档+回溯不恢复随机"成立**:SL 的本质是把随机变成免费神谕,穷举读穿骰子;不保存随机数状态关死这条路——每次回溯世界重新发牌,重试的收益不再是"这选项是错的"的信息,只是对自己判断的修正;烧掉的复盘能还(机制),推高的偏离度复盘不还——**可以试错,不可重播**。玩法层卖"历史不可逆",meta 层若允许免费回滚因果,游戏自相矛盾。劝退风险与护栏:① 档位词可逆推(剥夺的是精度不是可读性);② 归因链闭合(反噬判据+五流分离);③ 输局照样带走成就与图鉴,没有白局。结论:**只在"信息粗但因果清"的前提下成立——它不降低挫败,它保证挫败可归责。**

**人群与完成率目标(待实测校准)**:剧情——泛用户,60–80%(全信息+有存档+非致死+零代价退出,无撞墙点,流失集中在开局兴趣);普通——核心层,45–65%(时长两 session,靠存档;障碍是好结局的学习成本,复盘可分解学习);硬核——挑战层,**首通率不设线,改测"N 局内通关≥50%"**(无存档+信息剥夺+回溯重掷三重方差,首通含运气成分;opt-in 人群自选择)。三档不是三款游戏,是一个理解坡道:普通的数字口径就是硬核档位词的教材。
**调参纪律**:硬核大量流失时先查归因——复盘频率高+单局长=数值狠(在战斗,信能赢);复盘少+短 session 即弃+说不清输在哪=信息瞎。顺序:**先修信息后动数值**,且信息问题的修复是档位词粒度与因果呈现,**不是把数字还给硬核**(口径回退=硬核被溶解);归因成立而胜率仍不升,才动三组独立数值系数。配套:硬核需埋诊断(复盘次数分布、流失时点、未探索占比)。

## 3.5 结局与四维评分

**两层关卡**:能否判到某结局=先看**资格门**(当前偏离度∈结局声明区间),再看**判定树**(资格集合内按剧本写死优先级,高在前,命中即收束)。先池后分,命中逆天结局者总分×1.15——**资格先于分数**:四维再高、偏离度不到 71 摸不到逆天池;站上 71、四维平平也拿 1.15。
结局声明字段:名 / 印章 / 存续基准分 / 是否逆天 / 可用偏离度区间 / 判定条件 / 关联成就 / 史传文本 / 附注。
**印章为五值封闭词表,全剧本共用**:循史 / 苟活 / 稳健 / 逆天 / 败局。循史是系统语义位,触发史评下限保底(全作唯一系统主动托底);其余四值并列、无规则绑定;**不允许剧本自造,未匹配一律回落循史**。**拒载级校验**:词表外的印章值不会报错、只会静默显示成循史图——分不清是 bug 还是设计的失败,比报错难查得多,故必须加载期拒载。(技术债:稳健值图文件名与语义不对应,已记附录 A。)

**四维**(各 0–100;前两维你能做到,后两维世界给你;完整公式见 04 章):功业(权势峰值 0.6+事功分)/存续(纯结局注脚,唯一完全不由玩家行为参与——它权重 0.25 的理由在此)/史评(基准 50=中性线:**不主动经营史评你拿的就是 50**,循史另有 35 托底)/影响(**偏离度×0.6+功业×0.4**——偏离度的公共译本;"偏航未必立功,但偏航必然扰动"是公式直读)。
**史评加成旗标**:"史书里本该死去的人活到了结局"一类旗标直接加成史评,幅度不大;性质:奖励玩家做出**史书没写的选择**。与"修正不附带伏笔"同规则两侧:伏笔只能由玩家的手种下,世界的罚从不兑换成前途。
**事功对照表**:剧本数据逐项登记{官职|事迹→分值};未命中走**剧本显式声明的默认处理**(可声明不计分)——意图写在剧本里不藏在引擎里;漏配加载期报错拒载。

**合成**:`总分=clamp(0.35功业+0.25存续+0.20史评+0.20影响,0,100) ×难度系数 ×1.15^(是否逆天) ×0.98^回溯次数`。合成恒≤100,**破百只能来自系数——破百是需要争取的成就,不是数字习惯**。权重理由:功业最重(最难被局势白送、最吃主动经营);存续次之(不由人但定收束感);史评影响各两成(本质派生量)。
评级线:S≥85 / A≥70 / B≥55 / C≥40 / D。
**为什么三层不查表**:固定等级=奖品清单,S 是某个结局的名字,被评的是编写者押的题不是玩家给的卷——同一结局在"一手好牌做成的善终"与"众叛亲离边缘保住的善终"两个周目必须不同分。三层拆开:**落了哪一格由结局名/印章/史传回答(定性、有限、声明的);这一格被活成什么程度由四维/总分/评级回答(定量、连续、累积的)**;评级评的不是终点,是你到终点的方式。收集欲因此从"勾名册"转向"把同一格刷到不同分"——重玩经济的地基。
**涌现落点(可操作判据)**:是否存在"结局→分数"对照表?本作没有也不允许有。判定树/资格区间/事功分值/系数值是**规则侧有限声明(涌现的语法)**;四维读数、总分、评级、雷达形状是**整局轨迹经公式积分(涌现的语句)**。史评影响两瓣玩家不能直接操作、只能被记账——一个不擅争功的人影响可以很高:他的分数不在他的计划里,在他选择的涟漪里。规则全部明写,结果无一预写;这与史官笔法同构:谥号是有限词汇,而"你怎么写进传、后世评几分"从不查表——**由你全部的行状算出来**。
**史传体裁规格(回补定稿)**:史传=仿《史记》**史官断语体**,不是第二人称叙事体;要点:**事已至此,论其人,议其失——不下判决,只做盖棺定论**。它参与配音朗读与分享卡截取(见 07 章字段);偏文言、可拼进个人史的既有约束不变,但身份是"论"不是"叙"。
**结局页内容清单**(呈现规格归 07 章):结局名+印章+史传总结+四维评分+总分+评级+雷达图+分享卡+回溯入口。
**待观测(附录 A)**:段位×评级分布——若 S 过度集中于逆天档,说明偏离度双重计价(经影响 0.6 一次、经逆天系数一次,系明码标价的意图)压过了其他路线,调逆天系数。

## 4.2 四维完整计算式

**功业** = clamp(权势峰值×0.6 + 事功分, 0, 100);事功分=Σ 逐项对照表值(未命中走剧本显式默认处理)。输入=权势历史峰值、事功标记累计。
**存续** = 所落结局声明的存续基准分(无过程修正)。输入=结局格。
**史评** = clamp(50 + 历史分×0.5 + 旗标加成, 0, 100);印章=循史时史评≥35。输入=历史分(选项声明逐次累加,可负)、史评加成旗标、印章。
**影响** = clamp(偏离度×0.6 + 功业×0.4, 0, 100)。输入=偏离度、功业。
**合成** = 0.35×功业 + 0.25×存续 + 0.20×史评 + 0.20×影响(四维满格→合成恒=100)。

截断规则:四维一律截断到 0–100;合成值天然≤100;总分可破百(仅来自系数)。

## 4.3 三档难度完整系数表与体验描述

| | 危机系数 | 修正危机系数 | 总分系数 | 回溯 | 致死(危机≥100) | 属性/成功率显示 |
|---|---|---|---|---|---|---|
| 剧情 | 0.6 | 0.5 | 0.8 | 无限 | 否(100=封顶线,每章仍强制构陷直至降下) | 全数值+最终率 |
| 普通 | 1.0 | 1.0 | 1.0 | 每章一次 | 是 | 全数值+最终率 |

体验一句话:剧情=音量拧到六成、死不了人、随便回头,但总分恒八折,不走逆天评级天花板 A;普通=全额世界,标准 60–90 分,每次后悔折 2%;硬核=四重代价换全局最高系数,合成 70 即 S、可破百。
作用域纪律:危机系数与修正危机系数为**并行两条通路,不叠乘**;难度不得覆盖五列(全局锁定,保跨剧本评级可比);难度只调"承受",险招赔率全局单值不动。

## 4.4 回溯衰减曲线

`回溯系数 = 0.98^k`(k=回溯次数;硬核恒 k=0)。参考刻度(0.98^k):k=5→0.90、k=10→0.82、k=20→0.67、k=35→0.49。
举例(剧情,合成 100 时):k=0→80(A)、k=5→72.3(A)、k=10→65.4(B)、k=20→53.4(C)、k=35→39.5(D)。
**为什么永不为零**:0.98^k 无限趋零、永不到零——惩罚做成斜率而不做成断头台;玩家在任何时刻都保留"这一局还值得打完"的资格。不设下限,只设价格;停不停手玩家自己算——与"反噬是账单不是天罚"同一笔法。

## 4.5 系数咬合:分数里有多少来自选择,多少来自选了哪档

管线:`行局 → 合成[0,100] → ×难度 ×1.15^(是否逆天) ×0.98^k → 评级`。
同一合成值(如 100)的读数表:

| 组合 | 总分 | 评级 |
|---|---|---|
| 剧情无逆天 | 80 | A |
| 剧情+逆天 | 92 | S |
| 普通无逆天 | 100 | S |
| 普通+逆天 | 115 | S |
| 硬核无逆天 | 125 | S |
| 硬核+逆天 | 143.75 | S |

够 S 所需合成值:硬核+逆天 59.1 < 硬核无逆天 68 < 普通+逆天 73.9 < 普通无逆天 85 < 剧情+逆天 92.4 < 剧情无逆天(不可能,需 106)。
**诚实拆分(天花板局 143.75)**:合成贡献≈100=**70%**(行局表现);总分系数≈25=**17%**(开局点"硬核"那一下即定,唯一不是局内表现的部分);逆天系数≈**13%**(轨迹溢价:需偏离≥71 并活着落格,而偏离已经先经影响六折进过一次分——同一根轴,系统明码标了两次价)。剧情玩家则被结构性折价 20% 并随回溯持续放血。骰运不进分但改轨迹:烧毁烧掉的是事功与未来的旗标路径,运气经"选择被现实纠正"间接改写那 70% 的内容。
结论:评级=表现×你为自己选的处境,且处境部分全有价目表可查。

# 05 · 剧本包与写作规范

## 5.1 剧本包结构规范

**总定位**:剧本是纯数据,引擎不认识任何具体人物。剧本包=一份自足的内容资产;凡七组装不下的机制,不是"新剧本的需求",是"对引擎的新需求"(见 5.1.5)。

### 5.1.1 字段表(七组)

**① 剧本根**:标识(全局唯一)/局名/副题/年代/主角(仅呈现,引擎不读)/一句话简介/推荐定位(词表见 5.2.7)/难度块——**难度系数由全局基准表锁定,剧本包内仅为引用,五列一律不得覆盖**(跨剧本评级必须可比:一个 S 在任何剧本里都是同一个 S;危机系数若可覆盖,"硬核危机更重"就不再是硬核的定义)。

**② 属性侧**:属性注册表(十一维子集,缺省全开)/初始值(每维 0–100,按 P1–P5 人格原则)/风味档位词(维度×档位段→词;映射必须可逆推,词不塌缩)。

**③ 隐藏值(主敌)**:名称(展示文本,引擎不读)/初始值/**可感知章**(该章前完全沉默:不显示、不暗示、不留白——**不存在的东西在界面上不存在**;问号与灰条都是剧透)/档位词表(主角直觉口吻判断句,各难度一致,**永不与数值条同屏**——写成数字即降格为第十二维)。

**④ 章节树**:chapters[](index 0=序章,带教学注记)/每章{标识、标题、副题(年代区间|教学标注,必居其一)、章首注记(编剧元数据:年代+史实概要+设计意图,**不进玩家界面**)、章首旁白[](逐句渐显单元)、首个事件(∈本章 events)、events[]、行动池(12)、条件起点声明[]}。

**⑤ 事件**:标识(章-序)/标题(≤12 字不剧透)/叙事段落数组(1–3 段,首现实体带词条标记,引文带出处标记)/选项数组(2–4 项,至多 1 项标「史」;节点级事件必含 1 项)。
**选项六部分**:标题(≤15 字动词开头)/是否史实(布尔;为真=「史」标+史升档+效果方向与史载一致)/结算文本(必填,≤上限分级见 5.3)/失败文本(该选项存在软门槛路径→必填独立文本)/效果六类(属性变动/偏离度增量[≥0,负值拒载]/伏笔/成就[单键]/事功标记/历史分[±15 建议带,超者登记])/下一个事件(∈本章或"章末",不指回自身,图无环)/门槛(软=能力与状态量,硬=处境与事实固定词表——**行动卡同样可设软门槛险招**,与抉择页同套掷骰烧毁)。

**⑥ 行动卡**:标识/名(短跨本要求贴近事件链命名,见 5.3.5)/简述/门槛(可含软门槛;**财富在此=支付能力硬检查**——行动卡语境专属)/效果(属性变动/伏笔/事功标记;**结构上不带偏离度增量字段**——行动卡默认不改偏离度是定义不是遗漏)。

**⑦ 章级表+结局侧**:修正池(剧本级单数组恰 9 条,每条声明生效区间+触发概率+标题+文本+负向变动;正向 0,校验拒载)/成就表(8–12 条,单键声明三处封闭:选项效果直接声明/结局行反向关联/结局变体各自声明)/节点名表(标识+名+史实原貌一句话)/百科词条表(见 5.5)/事功对照表({事功标记→分值}逐项+**显式声明未命中默认处理**,漏配加载期拒载)/史评加成旗标表/结局表(有序=判定优先级;行内:名/印章/存续基准分/是否逆天/可用偏离区间/判定条件/关联成就/史传文本/附注)。

### 5.1.2 新剧本的边界

**必须交**:上述七组全部——粗略即"一个人的命运,以数据的形式完整落盘"。
**永远不交**:引擎代码、机制新词、判定规则实例。不引入词表外门槛键/效果类型/插入形态,不为单人单事开代码分支。
**边界的机器执行(加载校验清单,全部拒载级)**:字段齐全性·未知字段·门槛键不在词表·偏离增量为负·修正条目出现正向变动·事功标记未登记·next 指向不存在/成环·序章缺零代价退出闸·修正池条数≠9·结局区间存在无人可及段空洞·**词条全可达校验**(5.5)·成就空挂校验。**合规=纯数据,违规=体系溢出**——判定不靠评审自觉,靠加载器。

### 5.1.3 数据驱动的涌现:设计出来的,和凑出来的

**设计出来的涌现**(规则侧,真逻辑):反馈回路链式反应、选项集被状态裁剪、险招定价、真空区与三节奏、功业离散计分——哪怕剧本只有十个事件也成立;共同特征=可验证可学习,玩家能说出"我第几章做了什么→所以现在怎样"。
**规模凑出来的涌现**(组合侧,准逻辑):节点局面=状态×节点定义×分支流程的笛卡尔积;同一事件因手里伏笔不同亮出不同选项——没有一条被逐条书写,词汇量把可能性乘出来。负责"复玩不可预测",但单独撑不起"世界有逻辑"感——纯组合只是噪声。
**分工纪律**:凡玩家要归因的体验,必须落在设计侧;数据侧只负责让设计侧每次以新面孔出现。某段体验若只有数据量没有规则支撑(玩家只感到"不一样"说不出"为什么"),该数据按验收退回。

### 5.1.4 扩展成本(内容量级,以实测骨架校准)

| 块 | 量级/剧本(实测带) |
|---|---|
| ① 事件与选项 | 事件 18–31(实测均值 23.8);选项≈事件×3;每选项=标题+结算文本+效果向量(均 4–6 项);文本单元 250–400 |
| ② 行动卡 | 12×章数≈72–96 张 |
| ③ 章级表 | 修正 9(硬);节点名 10–15;成就 8–12;词条 20–46(实测李斯 46,余 20–37) |
| ④ 结局侧 | 结局 12–20(实测 74/5 本);事功表 30–60;史传 12–20 篇 |
| ⑤ 周边配置 | 初始值 11;档位词 55–90;隐藏值句 ~20 |

①占六成以上工作量且不可由引擎代劳(编剧成本);二至五高度模板化,可流水线。

### 5.1.5 引擎零改动纪律

**条文**:新增剧本禁止改引擎;加载校验器是唯一裁判。需求过不了校验时三问:①能否用现有词表代用(多数"新机制"是旧机制换主语)?②代用不了——是通用能力还是单剧本私例?私例→砍掉或降格,绝不开分支。③确属通用→扩引擎,走词汇表修订程序(新字段进 00 章词表、进加载器、进批量模拟覆盖,然后才允许剧本使用)。
**本质**:把"泛化的发现"推迟到第五次剧本的时刻——那时还无法说服自己这是私例,泛化才是真的。
**为什么是硬纪律**:① 成本结构——加剧本=加代码则边际成本最贵的是回归测试,数据-only 使剧本成为可独立制作、可外包给懂历史的人的内容资产(引擎一旦认识李斯,外包就死了);② 涌现主张可信度——玩家感到"世界有自己的逻辑",前提是同一副规则管所有剧本,每剧本改一次引擎=给"每个剧本都是另一款游戏"投一票,而卖点恰是同一引擎、不同命运;③ 逼你泛化——代码分支是拖延症,零改动把"通用机制还是私例"的判定强制压在新增当下做。**这条纪律保护的不是引擎代码,是这套体系还能继续长的能力:交一个人的命运,不交一行代码。**

### 5.2.1《仓鼠之局》李斯(7 章 31 事件 20 结局;新手向)

**定位**:唯一的全生命周期经营局——学艺、入秦、并天下、定制度、沙丘、狱死六幕;仓鼠哲学让每一幕都有可指的岔口,自由度五本最高。
**核心两难:相位与性命**。早退,一生所营尽弃;不退,恋栈本身就是沙丘之夜的全部前提。他的能力是真的(帝国机器离了他转不动),他的恐惧也是真的(布衣出身把权位当命根,是那个年代唯一可理解的执念)。玩家放弃的从来不是某个选项,是"不做丞相的李斯"这个身份。
**三路线**:苟活=逐客令前后或焚书前后交还相印归为上蔡布衣——路短、修正吃得少,终局"犬逐东门而人得全";稳健=宠信与权势双轨平衡,把暗流长期压在水线下,换"禄位终其身";逆天=沙丘那页的高门槛选项(联蒙恬的伏笔链+君心余量撑腰),奉扶苏诛赵高续秦祚——逆天池五本最大,因为它要对抗的不是军队,是一份已写好的诏书。
**主敌打法(朝臣)**:信息垄断(奏章诏命经手,谏言有概率不达)/近身控制(君心涨落取决于"会面质量")/法吏构陷(高危机时构陷条走"以国事整私仇"文本线)。压玩家的方式不是打,是**让玩家每次伸手都慢半拍**。
**差异化**:唯一把官僚系统本身做成对手盘的一本——其余四本的敌人都在门外,李斯的敌人住在同一间衙门里。

### 5.2.2《易水寒》荆轲(6 章 21 事件 16 结局;进阶向)

**定位**:唯一的一击定调局——六年意义凝聚为殿前几步;高密度短跨度,链环环相扣,岔口半径短、代价即时。
**核心两难:忠义与成算**。主君已疑("日已尽矣"),援手未至:现在动准备不足,再等信任与窗口同关。史书替他选了——带着怒气上路。**把命还给人情,还是把事交给理性**,两个合理选项互斥得干干净净。
**三路线**:苟活=不奉命,隐或遁,史书里他只是一个客卿;稳健=**以辩代刀**——刺杀改胁迫约盟,路线开门键在辩才不在文才(文学素养救不了燕国,嘴可以——本书立骨之笔,也是"分组是倾向不是规则"的示范);逆天=那一掷成功,此后燕存纵合——路线短促凶烈,逆天段修正照吃:救得了殿上那一刻,救不了殿外的天下。
**主敌打法(国王=目标本身)**:殿仪程序(剑法禁长、升阶跪奏)、符节核验、近侍环伺;戒心涨不是因为他疑你,是你靠近王座的方式被史书一条条"礼"堵死。压迫感来自**程序合法,没有阴谋可破**。
**差异化**:其余四本的时间是资源,这本的时间是引信;给先通李斯的人换一口不同的呼吸。

### 5.2.3《兵仙之局》韩信(7 章 25 事件 13 结局;容错中)

**定位**:唯一的双生结构局——前半段军事天赋的爽线,后半段同一套天赋变成死因的清算线;副题点破结构:提拔与处决由同一双手完成。
**核心两难:反与不反**。他在握着天平砝码的位置上;反,三分唾手但恩义与史笔俱毁;不反,功高震主四个字开始倒计时。**他是五本里唯一"能力足以赢、选择拒绝赢"的主角——两难不悬在能力缺口上,悬在人格上。**
**三路线**:苟活=从求高位封赏的那一刻起退让,不假王、不受印、解兵闭门——路线全部操作是**少做事**;稳健=军功与忠悃双账本,把"可反"的痕迹从履历擦净,换寿终;逆天=三分策成,要求同时通过军功软门槛链**和**"反"的不可逆声明(反,则早年忍辱攒的名声开始倒扣)。
**主敌打法(雇主)**:两次夺印、徙封调防(合法地换掉你的地盘)、耳目告发(部将舍人密报线),最狠的一件:**他从不亲自动手**。玩家所有应对本质都在回答"忠诚如何自证"——而它没有答案。
**差异化**:李斯输给自己的人,韩信输给信他的人;这一本让"胜利"本身成为门槛——打赢每一仗的同时,在输掉下一道判断。

### 5.2.4《霸王之局》项羽(7 章 22 事件 13 结局;绝径,容错 0–1)

**定位**:唯一的顺风局逆打——战场几乎不设阻,难在战场之外。**军功与人心两账反向走**:每赢一仗,"诸侯离心"涨一格——五本中唯一随玩家胜利而增长的压力线。
**核心两难:侠义与帝业**。他最认同的人是"破釜沉舟那个项籍",而帝业要他变成另一个东西;每一步"快意事"都在给离心值充值。**玩家放弃的,是让自己继续喜欢自己。**
**三路线**:苟活=不逐鹿,会稽后偏安江东,做一方霸王——结构上是五本最好走的活路;稳健=分封术,拉一个打一个,把离心运营在阈值下,换西楚长治;逆天=史实反面(关键殿上的一剑/用那个韩信/关中不移都),每条都要求玩家**不再像项羽**——凶险即在此:高门槛几乎全绑在"他的性格会拒绝"的选项上。
**容错悖论(本本必须写清)**:官方容错 0–1 与"苟活线最好走"不矛盾——**苟活要求玩家做的事,史书里的项羽绝不会做**:一个不肯过江东的人物,你偏要他偏安,于是苟活线上每一步都逆着人物性格、每步要额外门槛。项羽的凶险不在数值狠,在**活路要求自我背叛**;若坚持"像项羽一样活",就一路 march 向垓下。同一个"苟活",在李斯那本是顺势而为,在项羽这本是逆人格而行——**容错描述绝不跨本套用,根因即在此**。
**主敌打法(盟友集团)**:**没有反派**——每次叛离的文本里都写着充分理由(分封不均、质留不礼、求援不救);压迫感是复利的:战线越宽,每条战线背后都站着一个"你亲手续成的敌人"。
**差异化**:前几本的敌人可以识破、经营、躲避;项羽的敌人是他自己的战功。与陈胜对照成一句:一个死于心腹,一个死于盟友——同一句话写了两遍,一遍写"你提拔的",一遍写"你打败的"。

### 5.2.5《首义之局》陈胜(7 章 18 事件 12 结局;高难)

**定位**:最短、最陡、最孤独的一局——起事到身死链几乎无旁逸;独特处境:**第一个称王的人没有前例可抄**——"史实"参照系在他身上最薄(无史实选项事件仅 3 个是另一面:每一步史书都盯着,却每一步都没法抄)。
**核心两难:称王与"毋相忘"**。当王是起事的目的,而王者要杀故旧立威、要容忍火并、要把伙伴变成臣子。**当王,就要先杀那个说出"苟富贵无相忘"的自己**;不当王,首义火种无人执掌。史书替他选了第一条。
**三路线**:苟活=不建号,自居将不居王——要求他在起事那一刻把那句动摇天下的话咽回去(反他本人格的操作);稳健=纳谏固守、先建国后北伐,把称王换成一套制度——本本唯一真正的缓冲带;逆天=诸将听令、先锋入都、"首义"变"新朝"——要求他在史书每个节点做**他性格之外**的克制,难度即在此:逆天与循史在他身上是"当仁与不让"的拉扯。
**主敌打法(自己一手提拔的部将)**:**敌意的种子全部由玩家亲手种下**(前两章的每次封拜),后期三种收割:外将不奉令(分兵自立,章进度被偷)、将在外杀将夺功、近身最后一刀。玩家不能打击它——**打击它就是打击自己的班底**;只能经营信任,而信任是他最不会的事。
**差异化**:见 5.2.4 末句对照;本本容错"高难"不给数字——它的难在事件链窄与参照密,不同于项羽的"活路要求自我背叛",各按自身结构描述。

### 5.2.6 密度判决:行动卡是通用机制,不是任何一本的私人发明(已成立事实)

1. **机制不感知年历**:一章=一幕人生;卡的抽象层级由章自定义,章首旁白负责交代这一幕过了多久。
2. **实测反证**:五本合计 119 事件摊到 34 章(每章均值≈3.5,带 2.6–4.4),**每章事件数基本等量**——若机制依赖年代密度,短本会被迫每章十倍塞事件,数据没有发生。
3. **同一公式两种读法**:长章里收益递减编码**边际收益递减**(重复经营越来越没用),短章里编码**资源耗竭**(连续催征、代价原额照付)。公式一样,语义由密度给——这是泛化的真标志。
   结论:行动卡能同时装下七十年与四个月,引擎里没有任何一行代码知道年历。**将来问"这套东西能不能撑起唐或宋",本节即答案。**
4. 风险提示与处置:短跨本行动卡会与事件链抢"生活感";解法在写法层(卡命名贴近事件链、互为注脚,见 5.3.5),机制零改动。

### 5.2.7 定位词生效规则

- 两件事切开:**难度**(剧情/普通/硬核)=全局五列系数;**定位**(新手向/进阶向/容错中/**绝径**/高难)=剧本的结构禀赋(分支密度、零代价出口数、史实覆盖率、主敌静默期、逆天门槛高度)。定位词**不绑定任何数值**,只驱动选择器推荐序与一句话文案;"建议先通李斯本"是路径引导不是权限门。
- **命名交叉检查纪律**:定位词表与难度档名表任一字面重合=命名事故、拒载(旧"硬核定位"违规已改"绝径";现表零重合)。
- 文案护栏:定位词旁配释义模板("本局容错:约 0–1 条活线——指剧本结构,与难度档无关");**"高难"与"硬核"永不与难度档名同屏**——前者形容命,后者形容规则。
- UI 层细则归 07 章。

## 5.3 事件卡格式与写作规范(编剧照写)

### 5.3.1 格式模板与逐字段约束

(字段结构见 5.1.1⑤⑥;此处为写作约束,全部可检查。)
事件标题≤12 字不剧透;叙事 1–3 段,首现实体带词条标记、引文带出处;选项 2–4 项、至多一项标「史」、节点事件必含一项(纪律非机制);选项标题≤15 字动词开头,是"做什么"不是"感觉如何";结算文本必填;失败文本在存在软门槛路径时必填独立文本;效果六类;next 不指回自身、图无环;门槛键必在词表(偏离增量<0 拒载,属性越总则未登记拒载)。

### 5.3.2 写作规范清单(逐条可勾选)

- [ ] **C1a 防装饰(拒载级)**:每个选项至少改变一个状态量(属性变动或历史侧效果居其一);两者皆无=装饰选项。与支柱 1 判据同构,不另立标准。
- [ ] **C1b 配比纪律(观察项)**:带历史侧的效果占比应在**五成上下**;实测三成——**三成是设计成就**:绝大多数选择经营质地、少数触碰历史,偏离度才有意义、循史才住得住;每步都改史=永远逆天永远吃修正,段位当场失效。明显偏离→两种失衡之一("每步改史"/"全程经营终局才动一次"),亮黄灯。
- [ ] **C2 第二人称+意象**:含第二人称;意象删测——删去全部专有意象词后仍成立者判负(报告句)。
- [ ] **C3 险招独立失败文本**:有软门槛路径的选项必带独立具体失败文本,不复用通用句。
- [ ] **C4 史实锚+状态裁剪**:关键事件登记于节点名表;事件内至少一个选项带门槛或条件 next(否则选项集未被裁剪)。
- [ ] **C5 禁空洞心理**:情绪须以动作/物象/环境外化;整段无外化的纯状态形容句判负。
- [ ] **C6 引文标出处**:任何原文引用带出处标记字段,非空。
- [ ] **C7 词条用标记接住**:应成词条的实体首现处包词条标记;无标记=词条不可解锁(违反词条全可达硬校验)。
- [ ] **C8 禁现代词**:叙述域(非 UI 元数据)出现网络语、现代制度词、抽象社科词判负。
- [ ] **C9 每章事件数**:**每章≥2(硬校);2–6 为写作目标带**(陈胜 2.6/章实测所致,硬下限保 2)。
- [ ] **C10 结算文本长度分级**:常规≤60 字(中位 51);长结算 61–100 字仅限节点级事件且逐条登记;>100 不允许(现存 51 条超 80 字入豁免清单,定稿前逐条压或登记)。注:**0.5 秒铁律管反馈出现的时间,不管读完的时间**——上限服务"一小节一页/一眼读完"。
- [ ] **C11 史实标记一致性**:标「史」者 next 与效果方向须与该史书记载吻合;矛盾=伪标判负。
- [ ] **C12 节点必含史实**:节点名表登记的关键转折事件≥1 个「史」选项;非节点事件豁免(见 5.3.7)。
- [ ] **C13 序章零代价退出**:每本序章含 1 个零代价退出选项(系统项,见 5.4.4)。
- [ ] **C14 幅度总则**:单选项 ±2~±15、修正 ±5~±20,越界逐条登记豁免,无暗账。

(数字类 C9/C10 已按实测定稿;C5/C8 黑名单词表随 UI 章配套,见附录 A。)

### 5.3.3 叙事段落与结算文本的功能分工(为何必须分写)

叙事=**抉择前**、一事件一份、服务全部选项、史实(对手棋谱)、可铺陈;结算=**抉择后 0.5 秒**、一选项一份、随所选而变、玩家的偏离(可正可偏,进个人史)、一眼读完。
不能合并的三条硬理由:① 时序悖论——叙事在选择前,引擎还不知道选哪条,合并要么剧透要么把长文塞在每个选项前;② 铁律冲突——结算裹进长叙事=藏在角落=0.5 秒失效、卖点 2 崩;③ 对弈界面——分开写才有"史书在这里(叙事)↔我改了它(结算)"两个声道;合并=把对手的棋谱和我的落子糊成一段,参照系消失,重量感随之消失。

### 5.3.4 结算文本的三合一写法

一两句文本要同时是**即时反馈**(看懂:变了什么为什么)、**史书素材**(凝练可拼进史传)、**人物温度**(第二人称、这个时代这个人会说的话)。
写法:数字不入文本(变动由弹幕承载,文本被解放去写意义);外化意象替代状态形容("你听见殿外甲叶声退去"而非"你成功了");句短可独立引用(会被剪进史传与分享卡)。
**冲突优先级:即时反馈(清晰)>人物温度>史书素材(文言腔)**——写不到三全,先保看懂与像人说的,宁丢文言架子(史书性可事后由史传总结环节补,看不懂的选择反馈不可补);永不可让的是反馈(铁律兑现点)。

### 5.3.5 短跨度高密度本的写法差异(执行 5.2.6 风险条)

- **卡名贴近事件链的落地**:短本(荆轲/陈胜)每张行动卡的名字须能在**章首注记里指认它对应本章事件链的哪一环**——卡是同一批历史动作的后台操作面,事件是前台戏剧面(前台演"呼王/建号",后台卡即"署置官吏/遣徇郡县/拒来降"类);玩家读卡即读史,不产生"另一套无关小游戏"的抢戏感。长本(李斯)相反:卡在类别层抽象("督驰道""定文法"),不与单个事件一一对应——那是七十年经营的手感。
- 事件密度:短本章内串行为主少分支;长本分支密(史书给的"本可以"多)。旁白:短本短句场景锚定(引信感),长本可编年铺陈。
- 递减措辞分读:短本代价项写"资源耗竭",长本写"边际趋疲"——同一公式,文案随密度变语义。
- 护栏:短本每张行动卡的收益/代价文本须显式呼应本章事件链,写不出呼应=卡游离,退回。

### 5.3.6 正反例(判例存档)

**正例**(节点事件"沙丘夜访",示意):叙事段含出处标记、全外化("掌中一卷未系绳""屏退从人")、无心理形容;选项甲标「史」,结算"你想起上蔡东门那只逐人的仓鼠——这一次,是你替别人选了粮仓"(第二人称+意象+可入史传+不含数字),效果={权势+、君心−、伏笔"阿顺"、历史分−};选项乙带软门槛(君心)+硬门槛(伏笔·有"与蒙恬善"),独立失败文本("你话说得正,殿外却传来换值的脚步声")。过 C2/C4/C5/C6/C7/C12。
**反例**:"你做了正确的选择,声望增加了,心中暗自得意,未来的路更加宽广。"——判负四条:C8(现代词)+C2(属性名入文本、空泛无专有意象)+C5(心理无外化)+C10(四句冗长);实质违反 C1(只见属性不见历史侧)。改法:数字交弹幕,文本压成一句带意象的第二人称。

### 5.3.7 为什么 26 个"无史实选项"合法且必要

「史实选项」定义:**那个真实的人、在此刻、史书明载他会做的选择**。"无"不是漏写,是三种根本不存在参照系的情形:
① **后果型**:修正/反噬/清算/际遇下游——玩家在**承受世界对其既往选择的回应**;硬塞「史」=把"承受"伪装成"抉择",抹掉反噬"没有操作权、只有承受权"的本质。
② **无载型**:史书只记结果不记过程,标注即**让系统撒谎**。
③ **玩家原创型**:该节点因玩家此前偏航才存在,史书从无这一幕——它的对立面恰恰是"你不该走到这里"。
**分布即度量**(升格为跨剧本正式指标,5.2 已写):覆盖率=命运束缚强度;李斯无史实事件最多=自由度最高,与"新手向"互证。
**与涌现咬合**:参照系稀疏处=选项集全由状态裁剪、玩家无从抄答案之地——"我以为我够格"被现实纠正的密度最高。所以纪律不对称:**节点强制含「史」(玩家最需要坐标系处必有坐标),非节点豁免(让自由在毛细血管里生长)**。
反证:若强制全覆盖,编剧被迫给系统生成的清算编一条假正史选项——伪标污染参照系、承受被伪装成抉择、结构趋同摧毁五本差异化。**26 个缺口不是没做完,是刻意留白。**

### 5.4.1 数据结构与推进规则

2. 章内:事件经 next 走,结算后挂新关键卡;本章事件耗尽(或 next=章末)→**章末结算三步(属性面板→偏离度变化→修正判定)**。

### 5.4.2 章内进度口径:分母变了,玩家会看到什么

x=已通过抉择数(仅抉择结算计入);n=本章应历事件数=总数−跳过数。
**设计判定:局内静默,复盘显形,困惑转化为重玩钩子。**
- 局内:n 在第一回合开始前定格(含已扣减),全程不变——玩家察觉不到变过,因为变化不发生在感知窗口内(不是藏得好,是根本没有"看到分母跳变"的时刻)。
- 防"这章怎么这么快"式困惑:**错过不留白,错过留指纹**——章末面板一行"本章要事 x/n 节";与词条系统联动:被跳过事件关联的词条以"未解锁·待寻"幽灵卡呈现(规则见 5.5)——玩家知道"有个我没见过的故事",不知道内容。**把"分支存在"从困惑变成二周目动机**;零新系统(复用标记-词条链接);与覆盖率指标同构:参照系不仅指史书,也指你没走过的自己。

### 5.4.4 序章零代价退出闸(全局常项)

**为何必须有**:新手向的可信度来源——读完概念进本、发现读不动时,退出心理成本必须为零,否则"容错高"是谎话。
**系统定位(豁免锁死)**:**全局唯一豁免 C1a 的功能项**,显式系统标记:不参与效果统计、不入 C1a 校验队列、不入 C1b 配比——**它不是"没写效果的选项",是不属于抉择系统的功能项**,出现在抉择页只为让玩家在体验流里有自然出口。豁免范围仅此一项,每次新增必须重新审议(豁免一旦通用,第一个用它的会是偷懒的编剧)。
**退出后看到什么**:结算页中性文本("抽身而出"类);**不判死亡、不进结局池、不记成就、不产个人史、不污染图鉴与统计**——它不是一局,是一次翻书(防"白嫖侦察":开局看一眼再退、重开)。
**与教学共存**:旁白照常走完、首事件照常挂卡;退出选项与其他选项并列(无「史」、无门槛、无效果),选别的则序章正常进行——教学与退出两层皮,互不打断。

### 5.4.5 事件稀疏的真正解法(幕内密度版)

旧答案"用四十年跨度糊过去"已随 5.2.6 作废。每章 2–4 个事件凭什么不空——**四层填充,全部零新机制**:
1. **行动卡即章的血肉**:12 张池是"这一幕你在忙什么"的正面呈现;经营密度=生活密度。
2. **插入事件给呼吸**:甲类际遇与乙类构陷/反噬按规则挂入,章的实际内容=主线事件+插入,回合流没有"连续三回合无事可看"的死区。
3. **旁白锚时间**:一幕过了十年还是十天由旁白与副题(年代区间)一次说清——**时间感由叙事层供给,不由事件数量供给**。
4. **裁剪让事件内部变厚**:节点异变下,一个事件=状态裁剪的局面,选项集、失败文本、next 随人而异——**章的厚度在深度不在个数**。
验收纪律:批量模拟统计"章内无插入且平均>2.5 回合才关一个关键卡"的章判疏——修法先并入邻章、次选补节点事件;**不许塞无门槛无效果的凑数事件**(同时违反 C1a 精神)。

### 5.4.6 一根进度条,两种心理

陈胜的 x/n 与李斯的不一样——这不是缺陷,是这根条子的正确用法。
李斯(70 年 7 章):一章=一段仕途,「2/4」读作"本届任上还剩几件大事";陈胜(1.5 年 7 章):一章=一段生死,「2/3」读作"还剩几个节点没踩到死线"。同一 UI 元素承载两种语义而**功能一致:它量的从来不是时间,是幕的完成度**——"幕"正是五本共同的单位(5.2.6 的推论);时间单位由章标题与副题供给,不需要进度条代劳。
护栏(提案):短跨本章首注记的"设计意图"栏规定倒计时语气,旁白允许"距某败尚有 N 日"类句;长跨本禁滥用,防"每章都像处决日"的风格错位——升格为风格规范与否,见附录 A。

# 06 · 系统与元玩法

## 6.1 百科词条

**数据结构**:词条表=剧本数据,每条 {标识, 词条名, 所属章段, 史实层正文(带出处标记), 剧中层正文, 标记位反查表(引擎构建)}。量级实测:李斯 46,余 20–37。**跨局持久,按剧本分区。**

**解锁规则 R1(唯一入口)**:正文标记触发——渲染为可点词条卡,点击即解锁入册。**一句话:正文引用了它,它就是可解锁的。**推论:无标记位的词条不可解锁→违反 R3→拒载。
标记位语法(承 C7):标记只允许出现在三类文本块——事件叙事段落/选项结算文本/选项失败文本;UI 元数据、成就文本、章首注记内不算。

**R2 两层结构**:写法见 6.2。
**R3 全可达(硬性回归项,拒载级)**:每条词条至少存在一个可达标记位。**静态验证算法(加载器执行)**:
1. 建事件可达图:本章首个事件 ∪ next 闭包 ∪ 条件起点声明事件(入场条件按 R6 可满足性判定);
2. 建标记位索引:词条→所属文本块→所属选项/事件→该块是否在某条路径上可显示(失败文本块要求该选项存在软门槛路径;成功文本块要求该选项未被永久硬门槛锁死);
3. **旗标可满足性**:全剧本任一硬门槛"伏笔·有"所引旗标,必须存在至少一个可达选项声明种下它——否则引用它的选项/条件起点/标记位全部判死路;
4. 词条存在 ≥1 个通过 1–3 的标记位→可达;否则**拒载并输出不可达位置清单**。

**R4 未解锁·待寻(独立系统规则)**:凡因条件起点跳过而未进入的事件,其叙事段落内标记的全部词条,以**幽灵卡**呈现:显示词条名与所属章段,两层正文锁定。价值三条:①复用标记-词条链接,零新系统;②把"这章少了什么"从困惑翻转为二周目动机(承接 5.4.2 的指纹机制);③与"覆盖率=命运束缚强度"指标同构——参照系不仅指史书,也指你没走过的自己。
**R5 呈现**:词条卡点开不中断回合流(可关浮层);解锁瞬间给轻量提示,提示计入弹幕体系(R3 不阻塞),不打断叙事。

**词条正文两层写法**

| | 史实层(第一层) | 剧中层(第二层) |
|---|---|---|
| 写什么 | 此人/物/地/典**在历史上是什么**:身份、制度、沿革、存世状态;带出处 | 此物**在剧中的位置**:属于哪个体系、流经谁的手、关联哪些规则名词("本书诏令,皆出此手"——说位置,不说命运) |
| 不写什么 | 不写剧情、不用第二人称、不写"剧中"、不预写玩家命运、不代本朝作史评(史评留给印章与判词体系) | 不写玩家做了什么(静态文对多周目会产生错误泛化);不预支后续剧情("此诏后来成为你谋反的罪证"禁止);不剧透其他周目 |
| 文气 | 史笔,可短引原文 | 克制说明文,允许主角口吻冷幽默,禁止抒情 |

口诀:**第一层经得起查,第二层经得起猜**——玩家带着当前的选择读第二层,读到的是位置与可能,不是判决。

## 6.2 成就

**数据**:成就表=剧本数据,每本 8–12(实测李斯 12);**跨局持久,回溯不清除、读档不截断**(硬规则,6.5)。全局常项两条:①通用成就——**首次关键卡倒计时归零,被历史赶上**(五本共有;文案含义:你从不主动点开,历史自己来);②**任一逆天结局统一追加**。图标美术缺口按豁免登记(美术债务非机制债务)。
**声明点三类(封闭)**:选项效果直接声明/结局行反向关联/结局变体各自声明。**单键引用**:一个成就↔恰好一个声明事件,无布尔表达式。

**单键的写作含义(给编剧)**:成就必须挂靠**一件具体发生过的事**——一次点击、一个落格。禁止"同时满足 A 且 B"型成就;组合条件**不在成就层表达,在结局变体层表达**(判定树/变体行是复合条件的合法位置),"复合成就"改道为"一个变体结局+它声明的一个成就"。此限制逼成就写得具体——检查项:成就表逐条反查声明点;一个声明不允许多成就(防撒串),一个成就至少一处(空挂拒载)。

**命名三风格(均合法,按权重分配)**

| 风格 | 定义 | 适用 | 禁忌 |
|---|---|---|---|
| A 四字短语 | 无出处/淡出处凝练四字 | 系统/通用成就、章前段成就(一眼懂,先于理解文本存在) | 禁生造缩略;禁现代成语冒充古典 |
| B 成语化用 | 把后世熟语**归还给它的历史现场**,或反其意 | 玩家"知道成语但不知道现场"的成就(化用即注解) | 禁强行化用(需二次解释=失败);**禁晚于本朝成词的成语**(C8 在命名层的投影) |
| C 史书原句 | 直引/截取该人物本传原文 | 高权重成就,尤其死局与终章(史笔千钧自带) | 禁借他人之口(出处须本人本传/本纪);禁改动原句语义;截短仍须可读 |

分配纪律:**系统项用 A,中量级用 B,终局/死局级用 C——这本身就是稀有度的外显。**

## 6.3 为什么成就不能做成任务清单

任务清单=**完成条件**(问"我要求的事你做没做");成就应是**历史细节**(问"你碰没碰到历史的一个角落")。差别会反转编剧的写作方式:
- 任务清单式写法是**出题**("歼四将""入第 7 章")——玩家为勾清单而玩,攻略先行,历史成了副本进度;且单键限制下它们最"顺手",最容易写成,**必须明令拒绝:凡成就名+描述可改写成"去做 X"句式者,判任务味,退回。**
- 历史细节式写法是**埋点**:成就挂在原文时刻上——玩家读到那四个字才知道刚才那一步在史书里留下一行。**成就从攻略变成注疏:不要求你做什么,只标记你曾经在场。**单键限制在此显出真价值:它把成就绑在"一个具体发生过的句子"上而非待凑的条件组上——**绑定句子的成就天然就是细节**。
- 对卖点的作用:任务清单奖励"刷",历史细节奖励"读"——读,是核心层留下来的理由;且细节成就集合=分享卡上的"这人活过的证据墙",任务清单给不了那种东西。

## 6.5 硬规则:成就跨局持久——回溯不清、读档不截断

**分界线**:回溯清的(蓄势、烧毁)是**这条时间线上的状态**;不清的(成就、图鉴)是**玩家的册外之物**。一句话:**轨迹可以抹掉重来,见证不可以。**
**允许清除会怎样**:试错的损失若上探到 meta 层(成就被没收),理性玩家会收敛到零风险线——C1b 那七成经营质地退化为背答案,八结局三路线的重玩采样停摆,验证协议要观察的结局谱永远只采到"最安全的尾巴"。锚定判据在此闭环:**失败有尊严,前提是失败不没收你"曾经失败过"的权利。**
**与硬核无存档的关系**:两者同一条腿。硬核无存档无回溯——成就与图鉴是硬核玩家**唯一能跨局带走的记忆**;若清除截断,等于无存档模式连收集权都剥夺,1.25 倍评级没有任何持久物与之相配,挑战层人群的存在理由蒸发。反过来,硬核无回溯⇒硬核玩家**天然全成就纯净**——他的成就册每一行都是真走过、没回头的路。**无存档与不清成就不是两条规则,是一条规则的两面:硬核里你带不走的别想赖,带得走的别想抹。**

## 7.4 可读性与可玩性:书法字体的风险与处理(已确立=全局书法)

**已确立设定:本作全文统一使用书法字体**(该项先于本章确立;本章初稿曾提"展示层书法、阅读层宋/黑体"的分层方案,因与既定冲突,**降级为提案 P-7 移入附录 A**,正文按全局书法书写)。

**风险(全局书法自担)**:行草字形对无古文训练者不可读;长文疲劳;而 R2 逐句渐显、R9 完整呈现要求玩家**读完**——字形读不动,铁律被字体打折。

**处理(全部兼容于全局书法,不改用字)**:
1. **朗读同步逐句高亮**:配音(R6)与叙事区行高亮随音推进——读不动,可以听;
2. **异体字/通假字自动挂词条标记**(C7 延伸):不读即不识,不识由词条补课——书法的"读不动"降级为"不认识",而"不认识"恰是词条系统的本职;
3. **篇幅纪律托底**:叙事段≤3 段、长结算 61–100 字仅节点专用(C10 分级)——用文字密度限保住书法的可读下限;
4. **档位词取最高易辨字面**:词义模糊是设计,字形模糊是事故,两者不得叠加(此句为 P-7 提案的核心论据;全局书法下现以字面选择兑现)。

## 7.6 这套美术方向如何为「涌现」服务

不讲"水墨有历史感",只讲哪条视觉决策在替机制做事、替它省下哪一次解释:

1. **段位用色阶不用数字**:偏离度顶栏条按段变色(墨→青→赭→朱)——"世界用四种脸看你"必须一眼可辨,不需要读 0–100 的数;且**不可逆性由色彩记忆承担**(从朱回不到墨,色阶在替时间之箭说话)。数字只进结算页,颜色常驻视野。
2. **赤描边全局只留给乙类接管**:玩家学会"红边=题被换掉"只要一次;青只留给「史」,金只留给成就——**五枚记号的全局不复用,就是把"机制可学习"写进颜色**。涌现要可玩,前提是规则信号不串台。
3. **印章五枚制式=封闭词表的视觉固化**:朱文方印是史书定评的图形语言;五枚印、图形+文字双编码——**评级的"定性有限集"与四维的"定量连续"在画面上直接分层**,玩家看见印就知道"这是盖棺的,不是打分的"。
4. **史传断语体+书法**:盖棺的体裁配盖棺的字——书法用在"论"上(史传、印、节点名),印刷体用在"事"上(选项、结算);**字体的分工即涌现叙事的分工:事是系统算的,论是史官写的**。
5. **弹幕不阻塞**:R3 规定反馈是飘字不是弹窗——**世界先记账、不打断你翻书**,对弈的手感靠的是"落子声轻、棋谱不断"。
6. **年代线只跟随历史**:指针不可拖、只被结局推进——选择器在教玩家一件事:**进度不是位置,是走过的历史**。

一句话:**本章全部视觉规则的共同取向——让信号的语义密度最大化,让解释的文字量最小化;涌现要被人"看懂为自己的因果",靠的就是这些不解释的记号。**

## 8.1 技术选型:零依赖形态与它要解决的问题

**已确立约束**(来自设计):载体=零依赖 HTML5+JavaScript,手机浏览器直接打开即玩,也可上传 PC 端;配音用 Web Speech API(R6);竖屏优先单手可完成(R7);无任何外部服务依赖(离线可玩性——待核其成立性)。"零依赖"指**不依赖第三方运行库与构建产物**;打包形态(单文件/少量无依赖文件)待核(T-01)。

它要解决的问题不是"轻量",轻量只是表象。三个角度各一条:

**① 赛制时间(21 天)**:工具链是工期黑洞——依赖解析、版本冲突、构建配置每一项都吃日历,且吃的是**不可预测**的日历(今天装好明天崩)。零依赖把构建环节的方差压到近零:省下的每一天都投给内容(05 扩展成本表:事件与选项占六成工作量,那是人肉时间,工具帮不上)。**支撑:10 章里程碑的工期假设。**

**② 投稿门槛(可交付性)**:一个需要环境准备的提交,等于把"能不能玩"押在评审的耐心与设备上。零依赖的提交物=可直发的静态资源——发布链路最短、失败点最少。**支撑:赛制 H5/PC 端投稿通道(具体通道格式与限制待核 T-02)。注意:此条论证的是"链路短",不是"一定通过审核",审核规则本身待核。**

**③ 评审体验(3–5 分钟窗口)**:评审第一次打开的 30 秒内必须见到抉择页(卖点 2 的第一印象)。这意味着**首屏可玩、无需账号、无需下载、教程不挡门**(序章教学注记在页内完成,5.4.4)。**支撑:01 卖点 2 对"零延迟"的承诺从点击延伸到启动。**

**代价(如实登记,不粉饰)**:零依赖=所有非平凡能力(渲染、布局、存储、朗读、持久化)要么手写要么用平台 API——**开发时间从"集成"搬到"自研"**;跨浏览器/跨机型行为差异全部自担(兼容结论待核 T-03);没有生态兜底(出 bug 没有 issue 区可搜)。这笔代价买的是上三条收益,值不值由 10 章的交付实况检验。

## 8.2 模块边界与依赖方向

**职责分层**(这是设计要求的抽象层,不是文件结构;具体命名与落盘位置全部待核 T-04):

```
内容层(剧本包数据,纯声明)
   ↑ 只读引用
校验层(加载器:5.1.2 清单,唯一裁判)
   ↓ 放行后交
引擎层(规则解释器:回合机/判定/五条流/修正/裁剪纯函数)
   ↑ 状态变更唯一通道 ↓
状态层(局内态 · 跨局见证 —— 两域分离存储)
   ↑ 只读 ↓ 指令
呈现层(UI/输入/弹幕/朗读/分享卡)
```

**每层职责与它支撑的设计**:
- **内容层**:五本剧本的七组字段,无任何逻辑(5.1);**禁止**:引用引擎内部符号(键名映射表在本层由技术方案维护,不进 GDD)。
- **校验层**:加载即全量跑清单(字段/词表/可达性/成环/正向修正/负偏离/印章词表/条数计数),不过拒载并报具体位置;**支撑**:5.1.5"合规=纯数据,违规=体系溢出"的机器执法 + B42 拒载校验(防静默错图)。
- **引擎层**:全部规则的**唯一**实现地;对剧本零感知(不出现具体人物名/事件名的代码分支,05 纪律);随机为五个相互独立的流发生器,各自持有独立序列;**支撑**:五流分离承诺(8.4-1)、涌现可重放(05 5.1.1 裁剪层"体内禁一切随机源")。
- **状态层**:两域——**轨迹域**(手牌、倒计时、蓄势、烧毁、当局属性/偏离度;回溯=整域回滚到章首快照,随机序列不回滚)与**见证域**(成就、词条解锁、统计;回溯不清、读档不截,硬核导出恒空)。**支撑**:6.5"轨迹可以抹掉重来,见证不可以"——这句设计话在工程上就是两域的写回规则差异,存储不分离则规则无法兑现(T-05 验证两域边界)。
- **呈现层**:只读状态+发指令,不直写规则数值;弹幕、渐显、高亮、朗读、分享卡在此;**支撑**:R1/R3(反馈的时序与形态)、L1(数值不进正文的前提)。

**依赖方向规则(含"禁止项",可检查)**:
1. 内容层→引擎:**禁止**(剧本不认识代码,引擎才认识剧本结构)——违反即 5.1.5 失守;
2. 呈现层→引擎内部判定函数:**禁止直调**,一切经状态层指令通道——否则"0.5 秒反馈的时序"不受引擎控制,R1 失去工程保障;
3. 引擎→呈现:**禁止感知**(引擎产物=结算事件流,呈现自行编排节奏)——保证批量模拟可在无 UI 环境跑完(§7 T-06:无头运行能力待核);
4. 随机:五条流各自发生器,**禁止共享一个全局序列**(跨流串扰=重试换牌又换骰=8.4-1 破产);
5. 持久化:见证域与轨迹域**禁止混存同一键空间**(否则"硬核导出返回空"与"回溯不清成就"在同一次序列化里互相打架)。

## 8.3 继承:从废弃方案里保下来的那件东西

废弃的那份技术方案里,唯一值得保留的抽象=**数据驱动的人物包**。它在当前形态下的继承与改动:

| 废弃方案原样 | 继承为 | 继承时改了什么 |
|---|---|---|
| 人物包+回调(动态选项集是包内函数,如 optionsFor) | 剧本包七组纯数据字段(5.1.1);选项集被状态裁剪 | **函数改声明**:裁剪从"包代码算给引擎"倒转为"引擎纯函数读包声明"——换来可重放、可校验、可批量模拟(函数无法被加载器审,数据可以);英文标识符全面退出 GDD 正文(B27 教训) |
| 六维硬编码+隐藏值"国祚" | 十一维契约制(03)+偏离度显式化(B03) | 变量从"引擎内置语义"降为"key/label/good/init 数据声明"——五本共用一套维度语法,身外/自身的"倾向而非规则"由门槛形态承担(B10) |
| 单剧本单结局表 | 结局表+资格门+判定树三层(03/3.5) | 结局从"剧情终点"改判为"评分的一个输入":分数不查表、由整局积分(涌现落点判据) |
| 成就多条件表达式 | 单键引用三处封闭声明(06) | 复合欲改道结局变体——限制换来了"成就=历史细节"的可检性 |
| 太史公式判词等叙事装置 | 史传断语体参与朗读/分享卡(03/3.5,B43) | 独立判词元素清除,体裁本体保留——继承的分辨标准:**装置可废,体裁是结构** |

一句话:**继承的不是它的代码,是它的分层直觉;改动全部朝同一个方向——把"能执行的东西"换成"能审查的东西"。**这正是 05 零改动纪律在架构层的镜像。

## 8.4 这套架构如何贡献涌现(具体四处,不泛谈)

1. **五条独立随机流=涌现的"可证伪"前提**。涌现要可信,玩家得能检验"换一步走,世界是不是真的不同"——共享序列下这个检验永远被污染(你改了骰子也就改了牌)。独立流让"反事实重放"成为可能:固定其余四流,只换抉择→结局差异可指认为选择的果。**这是把 05 可重放验证从测试室交回玩家手里的架构决定**(玩家侧是否提供该能力=产品决策,附录待拍板 P-8)。
2. **裁剪层的纯函数约束=让"局面"可学习**。f(状态)无随机源→同一状态永远同一局面→玩家可以归因、第二局可以策略化。涌现的交互面(05 5.1.3"设计侧支撑")在架构上就等于这一条:**随机住在调度,不住在内容。**
3. **加载器=涌现语法的边界守卫**。拒载清单里的每条(负偏离/正向修正/印章表外/成环)都是"**不允许非涌现的数据进入涌现引擎**":能回滚的偏离度、会发糖的修正、自造的印章,全部进不了门。**涌现不是引擎的宽容,是输入的纪律。**
4. **状态层两域分离=时间之箭的存储形态**。轨迹域可快照回滚(章首快照,5.4)、见证域只进不滚(6.5)——一局之内的"可试错不可重播"、一局之外的"失败有尊严",最终都要落到"谁在哪次写回里被抹掉"的存储事实上。**不可逆性是一种持久化策略。**

# 09 · 验证协议

> 本章读者:评审与接手维护的人。他们要判断的不是"平衡得好不好",而是**你有没有能力知道自己哪里错了**。
> **中心命题:可证伪性。** 本协议里的每一条验证,都必须能回答同一个问题:"观察到什么,就算推翻它?"答不出的,不配进断言,只能进试玩记录——且必须被诚实标记。
>
> **本章纪律:凡具体数字一律标待核**,除非它是已给锚。已给锚共六处:基线扫描规模(五剧本各 1000 局、种子 100 组)、三策略对照、单属性策略=压力测试非门槛、删项审计"约二十组种子量级"、增量"十点"跳段疑似线、修订"先文档→再代码→补断言,三者同批"。其余数字全部锁入 §8 待核清单。

## 9.0 两项原待决的结案登记(已确立,入本节)

**① 删项审计**——原"逐开关全量对照"不可行(成本=选项数×局数),改**固定种子对照**:同一组随机数种子下,开着某选项跑一遍、关掉再跑一遍,比较两遍的结局分布。固定种子消除噪声,单组种子即可判方向,成本降至约二十组种子量级(锚)。三条落地规则:
- **审计对象**:只取带历史侧效果的选项(装饰问题高发区);纯属性经营类由静态三查(P-1)覆盖,不动用模拟;
- **判定标准**:分布位移,不追求统计显著——同一结局占比在开关两态下**方向一致的位移**(超过最小报告地板,地板值待核 V-04)即判"有重量";二十组种子全部零位移→判装饰,退回内容;
- **留档**:每项审计存档(选项名、两态分布、结论),存档本身即内容评审的证据链。

**② 偏移敏感性测试**——拆为两件事,都带验收线和修法:
- **边界稳定性**:四段位边界各做 ±5 点扰动(锚),重跑基线。验收(待核 V-02):单条边界扰动五点,**任一结局占比变化≤N 个百分点**;超→说明该边界落在门槛聚集区,边界位置是武断的,复核=挪边界或挪门槛,复测收敛才放行;
- **增量分布**:统计每次抉择的偏离增量直方图。验收(待核 V-03):>10 点(锚)的单步增量占比≤上限;超限→存在"两三个选择从循史冲到改流"的跳段路径,四段位设计失效——**段位的意义在于停留,不在于抵达**;修法=把大额增量拆档或压单步上限,复测直到直方图主体落在 0–9。

## 9.1 验证体系总览

| 类 | 负责发现 | 不擅长发现 | 互补关系 |
|---|---|---|---|
| **静态校验**(§9.3) | 单条数据的合法性:词表、计数、结构、可达性 | 组合才显形的问题 | 零成本全量扫描,一切动态验证的前置门卫 |
| **回归断言**(§9.4) | 单条规则的确定性偏差(改一处坏一处) | 规则本身设计错误(断言只是把设计固化) | 守"改对的东西没被改坏" |
| **批量模拟**(§9.2) | 分布层面的意图偏差(路线可达性、段位×评级) | 局部 bug(它只看统计,不看单次) | 守"规则们加在一起还是不是设计的那句话" |
| **删项审计/敏感性**(§9.0) | "重量"与"边界"的因果性问题 | 常规平衡 | 守"涌现是真的还是噪声/装饰" |
| **试玩与状态稿**(07 S1–S19) | 体验性命题(可读、手感、盖棺感) | 一切数值 | 不可证伪命题的唯一法庭,见 §9.7 |

**为什么必须不止一种**:每种验证只能发现"它被设计出来要发现的那一类问题"。静态校验能发现第 9 条修正带正向,永远发现不了"三路线其实只有一条活着";回归断言能守住 0.98^k,永远测不出"S 全部堆在逆天档"这种全体合规却意图破产的分布;模拟看分布,看不见一次错误的状态转移。**一套只有一种验证的协议,等于承认自己只会犯它没装备的那类错。**

## 9.2 批量模拟协议

**运行前提**:引擎可在无界面环境跑完一局(依赖 T-06/V-07 待核;无头能力不成立则全协议悬空)。

**规模**(锚):基线扫描=五剧本各 1000 局;种子=100 组,每局随机取种;**种子必须显式入参并随报告存档**——可复现性是本协议第一条款。

**策略集**(锚:三策略对照+单属性压力):
- **苟活 / 稳健 / 逆天** 三策略,各自对应一条路线的玩家表达(决策函数=按该路线的目标函数选当前最优选项;函数实现归 V-09 待核);三策略对照的用法:验证三条路线**同时活着**——任何一条策略的结局谱塌缩成单点(比如稳健 99% 同结局),即判该路线未成立;
- **随机对照组**(建议入固定协议,待核 V-10):全部选项等概率,充当"可达性地板"——随机能到而三策略到不了的结局=设计意图外的暗道,随机到不了的结局=近乎不可达,两头都要查;
- **单属性策略**(锚):**压力测试,不是门槛**。每个维度各配一条"全押该维"的探照策略;不为其设任何通过率,只看它的分布形态——若单押某一维(尤其危机归零、君心满值类)稳定滚到 S 或稳定死局,说明该维"被送"或"一票否决",上报人工复核。**口径落地**:验收报告里单属性策略的列永不参与通过/不通过判定,只出现在"异常形态警报"区。

**报告字段**(具体字段名待核 V-01):结局谱分布、段位×评级交叉表、路线可达矩阵(8+结局×3 策略)、决策点数直方图(对 15–22 带)、历事/分支深度、偏离增量直方图(喂 9.0-②)、历史侧配比(喂 C1b 五成带)、险招档位选择分布(含"差 4 弃赌"频率)、蓄势使用率(含"章末蓄势/跨章兑现"计数)、构陷/反噬承受后的存活力曲线。

**判定标准**:O 系列观测项(§9.5)的期望形态;三策略路线存活;基线与上一轮存档的漂移告警。任何一项不达标→不自动修数值,先回 9.6 判定该修内容、规则还是边界。

## 9.7 这套验证体系如何为主题服务

**涌现难测,那就把"测什么"说穿**:

**可证伪的(归本协议)**:① 规则确定性——f(状态)对同状态恒等、五流互不污染、重放逐字节一致;② 账本不变量——单调不减、clamp、两域写回矩阵;③ 管线公式——四维/系数/评级线对 golden 值;④ 因果性——删项审计(没有它,结局位移归零即它不承重)、敏感性(边界不武断、不跳段);⑤ 统计形态——O 系列全部"分布形状"。**每条都满足"观察到什么就推翻它"。**

**只能试玩判断的(归 07 状态稿+试玩记录,模板待核 V-08)**:这页文言读不读得动、0.5 秒像不像即时、20 点断崖有没有被"体感"到、印章落下有没有盖棺的重量、失败有没有尊严。它们**可评审、不可证伪**——没有断言能证明"手感对了"。

**边界的守则(谁守)**:**条款的形式声明,由本章 §9.5/9.7 起强制**——每一条验收条款必须标注 [可证伪]/[可评审]。[可证伪]进 §9.4 断言与 §9.2 扫描;[可评审]进 07 状态稿与试玩记录(记录格式:谁、何时、哪张稿、结论三态:过/不过/存疑)。**这条边界由写条款的人守、由 CI 的标注完整性检查兜**——它防的是两种对称腐败:把体验伪装成数据("我觉得手感对"进不了验收,除非有分布背书),以及把数据伪装成体验("这个曲线应该平滑"不进不了断言,除非写出推翻条件)。

主题收束:**"结果来自规则相互作用,而非预设剧本"——这句话本身就是一个可证伪命题。** 删项审计测"预设"(假重量),敏感性测"剧本"(武断边界),O-1 测"结果"(分布是否真的由相互作用长出来)。验证体系不是平衡的保姆,是涌现主张的法庭:每章设计说的话,都在这里有一句对应的"凭什么信你"。

## 10.4 五篇怎么排才同时满足"不连发"与"真实过程"

**间隔三规则**:① 相邻 ≥2 天(上表:5→8→11→14→16,最小间隔 2 天,全部"非一天内连续发布");② 末篇 ≤10.16/17,给 10.18 建议日留缓冲,也给"日志须与开发进度同步"的赛制语义留出真实感;③ **每篇绑定一个"当日才存在的事实"**——这是反灌水条款的工程化:日志不描述计划,只描述今天已经红过/绿过/亮过的东西。

## 10.5 推翻档案怎么用

**为什么它比"我们做了什么"更符合"真实记录"**:评审对灌水的判据是"内容与作品无关、空洞重复"——而一篇只有"做了什么"的开发日志恰恰最容易滑向这两条,因为**成就叙事没有证伪点**。"真实"的操作定义是可检验的过程痕迹:谁、在哪个时刻、以什么证据、推翻了什么。附录 B 的 43 条每一条都是这三元组(B41 烧毁三元组修正:开发方自纠;B16 规范与数据打脸:以数据为准修规范;B39 自查抓到 D→C 误记)。**一份满篇"我当时想错了"的档案,无法伪造——它的每一行都带可回溯编号,连"发起方"这一列都区分了开发者裁决与 AI 自抓。**

**怎么组织成可发布的日志**:不全量倾倒(那是格式怪)。用法=**一弧一篇**:每篇日志取与当日主题同侧的 2–4 条,按固定叙事模板写——"当时我以为 X(编号)→ 证据 Y(数据/纪律/试玩)出现 → 现在 Z"。示例:L3 用 B01/B02(方向转折弧)+B16/B17(规范被数据打脸弧)+B39(自己抓自己弧);L4 用 B10(身外一律硬门槛那堵承重墙)说明为什么"壳"之外还有"规则适配"的暗成本。**档案的另一重身份是协作诚实度**:43 条中发起方为"AI 自查"的 9 条,是这个项目"人机分工"最无装饰的证据——评审若关心 AI 参与,没有比"AI 列出自编错误清单"更强的回答。

### 详细介绍(约 650 字,可独立读,承担试玩转化)

> **这是一台历史偏移模拟器。**你重生为历史人物,从人生的第一个岔路口开始,不断做出抉择。
>
> 游戏里有一条你看得见的尺:**历史偏离度**,0 到 100,只增不减,分循史、微澜、改流、逆天四段。它量的是历史对你的预测失效了多少——顺从史实,世界按熟悉的剧本运转,安稳;逆天而行,你确实改变了什么,但历史会开始清算你:每过一段,它就要收一次账。
>
> 收账的方式不是数值惩罚,是**遭遇**。沙丘那一夜会有人推开你的门,先帝的玺书压在他袖中;史书写你该死的人,可能因为你当年的一个选择活着——也可能死得更难看。每一个决定点下去,半秒内弹出结果与代价,然后才轮得到叙事往前走。
>
> 玩法以卡牌回合推进:每回合你手里三张行动卡、牌桌中央一张压着倒计时的事件卡。**打出的牌越多,事件来得越快——但没人告诉你那个事件是什么。**你知道劫数要来,不知道是哪一道,只能按最坏的情况准备。这是你和历史对弈的棋钟。
>
> 选项上有一个"史"字标记,告诉你史书里的那个他怎么选。不达标的大胆选项不锁死,给你赌——按差距标价,掷骰定成败,输了这条做法当场作废。顺从史实概率会高一点,但封顶七成:历史给的是概率,不是承诺。
>
> 活到最后,游戏替你写一段仿《史记》体的个人史传,盖一方印章(循史、苟活、稳健、逆天、败局),配四维评分:功业、存续、史评、影响。评的不是你到了哪个结局,是你把那个结局活成了什么程度——同一格,两次周目,两分数。
>
> 零依赖网页,手机浏览器点开即玩,竖屏单手。单局约一小时,五种活法。历史不给你保证书——现在,你来。
